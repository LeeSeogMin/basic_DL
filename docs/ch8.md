# 8강. 중간 미니 프로젝트: 나의 첫 AI 모델

## Part A — 강의 (1교시, 90분)

### 강의 목표

이번 강의의 목표는 1~7주차에서 배운 개념을 하나의 작은 프로젝트로 연결하는 것이다. 새로운 이론을 추가하지 않는다. 대신 데이터, 모델, 학습, 평가, 과적합, AI 도구 활용을 한 흐름으로 경험한다.

학생은 이번 시간 후 다음을 할 수 있어야 한다.

1. 문제 정의부터 데이터 준비, 모델 선택, 학습, 평가까지 한 흐름으로 수행한다.
2. 모델이 잘하는 것과 못하는 것을 구분해 설명한다.
3. AI 코딩 도구를 사용한 과정을 기록하고, 직접 검증한 부분을 명시한다.
4. 실패 사례를 숨기지 않고 분석한다.

이번 강의는 정확도 경쟁이 아니다. 모델이 완벽하지 않아도, 왜 틀렸는지 설명하면 좋은 프로젝트다.

### 핵심 개념

이번 주에 새로 배우는 개념은 없다. 대신 1~7주차의 핵심 개념을 프로젝트 맥락에서 다시 확인한다.

| 주차 | 핵심 개념 | 프로젝트에서 확인할 것 |
|---:|---|---|
| 3 | 데이터, 특성, 라벨 | 내 프로젝트의 입력 데이터와 정답은 무엇인가 |
| 4 | 분류, 기준선, 정확도, 혼동행렬 | 내 모델은 기준선보다 나은가, 어떤 오류가 많은가 |
| 5 | 퍼셉트론, 은닉층 | 내 모델은 단순한 모델인가, 신경망인가 |
| 6 | 손실함수, 학습률 | 학습이 실제로 진행되는가, 손실이 줄어드는가 |
| 7 | 과적합, 일반화 | 훈련 정확도와 테스트 정확도의 차이는 얼마인가 |

### 8.1 프로젝트란 무엇인가

매주 실습은 정해진 코드를 실행하고 결과를 해석하는 활동이었다. 프로젝트는 다르다. 학생이 직접 다음을 결정한다.

- 어떤 문제를 풀 것인가
- 어떤 데이터를 쓸 것인가
- 어떤 모델을 선택할 것인가
- 결과를 어떻게 해석할 것인가
- 실패 원인을 어떻게 분석할 것인가

프로젝트의 핵심은 "정확도가 몇인가"가 아니라 "왜 이런 결과가 나왔는가"다.

### 8.2 주제 선택

다음 유형 중 하나를 선택하거나, 비슷한 규모의 주제를 정한다.

| 유형 | 예 | 관련 주차 |
|---|---|---|
| 취향 분류기 | 영화/음식/음악 취향으로 유형 분류 | 3, 4주차 |
| 작은 이미지 분류기 | 손글씨 숫자, 간단한 도형 분류 | 4, 5주차 |
| 댓글 감성 분류기 | 리뷰 문장을 긍정/부정으로 분류 | 3, 4주차 |
| 표 데이터 예측기 | 학생이 만든 표 데이터로 예측 | 3, 4, 7주차 |

좋은 주제의 조건은 다음과 같다.

- 수업 시간 안에 최소 결과를 낼 수 있다.
- 데이터를 구하거나 만들 수 있다.
- 정답이 분명하다(분류의 경우 라벨이 있다).
- 본인이 관심 있는 분야다.

피해야 할 주제는 다음과 같다.

- GPU 없이 실행할 수 없는 대형 모델
- 데이터를 구할 수 없는 주제
- 정답을 정의할 수 없는 주제
- 프롬프트 결과만 붙여넣는 것

### 8.3 프로젝트 계획서

프로젝트를 시작하기 전에 다음 양식을 채운다. 계획서는 완벽하지 않아도 된다. 프로젝트를 하면서 바뀔 수 있다. 중요한 것은 시작 전에 한 번 정리하는 것이다.

```text
프로젝트 제목:
문제:          (무엇을 예측 또는 분류하는가)
데이터:        (어디서 가져오거나 어떻게 만드는가)
모델:          (어떤 모델을 쓸 계획인가)
평가 방법:     (정확도, 혼동행렬, 손실 곡선 등)
예상 어려움:   (데이터 부족, 코드 오류, 과적합 등)
AI 도구 계획:  (어떤 도구를 어떤 작업에 쓸 계획인가)
```

### 8.4 필수 제출물과 평가 기준

| 제출물 | 설명 |
|---|---|
| 실행 코드 | GitHub 저장소 또는 Colab 링크 |
| 결과 화면 또는 로그 | 코드가 실제로 실행되었음을 보여준다 |
| 실패 사례 3개 | 모델이 틀린 예시와 원인 분석 |
| 책임 있는 AI 체크리스트 | 개인정보, 출처, 과장, 보안 점검 |
| 3분 발표 자료 | 문제, 데이터, 모델, 결과, 실패, AI 활용 |

평가는 다음을 본다.

| 잘한 프로젝트 | 부족한 프로젝트 |
|---|---|
| 모델이 틀린 이유를 설명한다 | 정확도 숫자만 있고 해석이 없다 |
| AI가 도와준 부분과 내가 고친 부분을 구분한다 | AI가 만든 코드를 그대로 제출한다 |
| 과적합 여부를 확인한다 | 훈련 정확도만 보고 모델이 좋다고 한다 |
| 실패 사례를 기록한다 | 틀린 사례를 숨기거나 없다고 한다 |
| 코드가 실행된다 | 코드가 실행되지 않는다 |

### 핵심 정리

- 프로젝트는 정확도 경쟁이 아니라 "왜 이런 결과가 나왔는가"를 설명하는 활동이다.
- 수업 시간 안에 최소 결과를 낼 수 있는 주제를 선택한다.
- 실패 사례는 감점 대상이 아니라 학습 자료다. 숨기지 않고 분석한다.
- AI 도구를 사용할 수 있지만, 사용 기록과 검증 과정을 함께 제출한다.

## Part B — 실습 (2교시, 90분)

### 실습 목표

이번 실습의 목표는 프로젝트를 실제로 시작하고, 수업 시간 안에 최소 결과를 만드는 것이다.

학생은 이번 실습 후 다음을 할 수 있어야 한다.

1. 프로젝트 주제를 확정하고 계획서를 작성한다.
2. 데이터를 준비하거나 생성한다.
3. 최소한 하나의 모델을 학습시키고 결과를 확인한다.
4. 발표에 포함할 내용을 정리한다.

### 실습 절차

#### 단계 1: 주제 확정과 계획서 작성 (10분)

1교시에 소개한 프로젝트 유형 중 하나를 선택한다. 계획서 양식을 채운다. 교수자 또는 조교에게 주제를 확인받는다.

#### 단계 2: 데이터 준비 (15분)

- 3주차 실습 데이터를 확장하거나, 공개 데이터셋을 사용하거나, 합성 데이터를 만든다.
- scikit-learn의 `make_classification`, `make_moons`, `make_circles` 등을 쓸 수 있다.
- 합성 데이터를 사용하면 반드시 합성 데이터임을 표시한다.
- 데이터에 개인정보가 포함되지 않았는지 확인한다.

#### 단계 3: 모델 학습과 평가 (25분)

- 4~7주차에서 사용한 분류기(로지스틱 회귀, 결정 트리, MLP 등)를 적용한다.
- 기준선 모델과 비교한다.
- 정확도와 혼동행렬을 함께 확인한다.
- 훈련 정확도와 테스트 정확도를 비교해 과적합 여부를 확인한다.

#### 단계 4: 실패 분석 (15분)

- 모델이 틀린 사례를 최소 3개 찾는다.
- 각 사례에 대해 "왜 틀렸을까"를 한 문장으로 적는다.
- 판단 경계 근처의 점인지, 데이터가 겹치는 부분인지, 모델이 배우지 못한 패턴인지 구분한다.

#### 단계 5: 발표 준비 (15분)

3분 발표에 포함할 내용을 정리한다.

1. 문제와 목표 (한 문장)
2. 데이터 (몇 개, 어떤 특성, 합성인지 실제인지)
3. 사용한 모델
4. 결과 (정확도, 혼동행렬)
5. 실패 사례 (최소 1개)
6. AI 활용 (어떤 도구로 무엇을 했는가)
7. 배운 점 (한 문장)

### AI 활용 가이드

이번 실습에서 AI 도구는 다음 역할을 할 수 있다.

| AI에게 맡길 수 있는 일 | AI에게 맡기면 안 되는 일 |
|---|---|
| 코드 작성 보조 | 프로젝트 주제 결정 |
| 오류 메시지 설명 | 결과 해석과 실패 분석 |
| 데이터 시각화 코드 생성 | 발표 내용 전체 작성 |
| 모델 선택 제안 | 이해하지 못한 코드 제출 |

### 결과 해석

이번 프로젝트에서 주목해야 할 점은 다음과 같다.

- 기준선보다 모델이 나아졌는가. 나아지지 않았다면 데이터나 모델을 점검한다.
- 훈련 정확도와 테스트 정확도의 차이가 크면 과적합을 의심한다.
- 정확도가 높아도 혼동행렬에서 한쪽 오류가 집중되면 모델의 약점이 있다.
- 모델이 틀린 사례를 분석하면 데이터의 한계와 모델의 한계를 구분할 수 있다.

### 책임 있는 AI 체크

| 점검 항목 | 확인 질문 |
|---|---|
| 성능 과장 | 정확도 하나만 보고 모델이 좋다고 단정하지 않았는가 |
| 실패 기록 | 모델이 틀린 사례를 최소 3개 기록했는가 |
| 과적합 확인 | 훈련 정확도와 테스트 정확도를 함께 확인했는가 |
| AI 기록 | AI 도구 사용 과정을 프롬프트와 함께 기록했는가 |
| 개인정보 | 데이터에 실제 개인정보가 포함되지 않았는가 |
| 코드 이해 | AI가 만든 코드를 이해하고 직접 실행했는가 |
