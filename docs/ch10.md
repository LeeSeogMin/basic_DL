### 1. 자연어 처리란

○ **자연어 처리**(natural language processing, NLP) — 사람이 쓰는 말과 글을 컴퓨터가 다루게 하는 분야
  - 자연어는 한국어·영어처럼 사람이 일상에서 쓰는 언어이고, 프로그래밍 언어와 구별하려고 붙인 이름이다

○ **컴퓨터는 글자의 뜻을 모른다**
  - 파일 안에서 '가'는 44032번, '나'는 45208번 같은 번호로 저장된다
  - '가'와 '나'의 번호 차이는 1176, '가'와 '개'의 차이는 28이지만, '가'가 '개'에 더 가까운 낱말인 것은 아니다. 글자 번호에는 뜻이 없다
  - 그래서 문장을 모델에 넣으려면 뜻이 비슷한 문장이 비슷한 숫자를 받도록 바꾸는 단계가 필요하다

![문장 한 줄이 숫자 벡터가 되기까지의 네 단계](../practice/chapter10/results/fig10-1-text-to-vector.png)

**그림 10.1** 문장 → 토큰 → 사전 → 벡터. 마지막 줄 `[1, 1, 1, 0, 0]`이 모델에 들어간다. 그림은 개념을 보여 주려고 손으로 만든 도식이다

○ **자연어가 어려운 이유**
  - 같은 낱말이 여러 뜻을 가진다. "배"는 과일, 탈것, 몸의 한 부분일 수 있고, 앞뒤 문장을 봐야 뜻이 정해진다
  - 같은 뜻을 여러 낱말로 쓴다. "배송이 빨라요"와 "택배가 하루 만에 왔어요"는 겹치는 낱말이 없지만 같은 이야기다
  - 한국어는 낱말 뒤에 조사와 어미가 붙는다. "배송이", "배송은", "배송도"는 컴퓨터에게 서로 다른 글자 줄이다

### 2. 자연어 처리가 하는 일

같은 문장을 넣어도 무엇을 출력하게 하느냐에 따라 작업이 달라진다.

**표 10.1** 문장으로 하는 대표 작업

| 작업 | 컴퓨터가 내놓는 것 | 예 |
|---|---|---|
| 텍스트 분류(text classification) | 문장 하나에 이름표 하나 | 뉴스 제목의 주제 가리기(실습 10.2), 리뷰가 긍정인지 부정인지 |
| 토큰 분류(token classification) | 토큰마다 이름표 하나 | "서울에서 김철수가 주문했다"에서 "서울"은 장소, "김철수"는 사람이라고 표시하기 |
| 문장 유사도(sentence similarity) | 두 문장이 닮은 정도를 나타내는 숫자 | 비슷한 문의 글 찾기 |
| 특징 추출(feature extraction) | 문장이나 단어의 벡터 | 문장을 벡터로 바꿔 검색·추천에 쓰기 |
| 질의응답(question answering) | 질문에 대한 답 | 제품 설명서에서 "충전 시간은?"의 답 찾기 |
| 요약(summarization) | 짧게 줄인 글 | 긴 회의록을 몇 줄로 줄이기 |
| 번역(translation) | 다른 언어로 옮긴 글 | 한국어 기사를 영어로 옮기기 |
| 텍스트 생성(text generation) | 이어지는 글 | 다음 단어를 예측해 문장 이어 쓰기(11장) |

_참고: 작업 이름은 Hugging Face Tasks 페이지(https://huggingface.co/tasks, 2026년 11월 확인)의 Natural Language Processing 분류에서 골랐다. 각 작업의 예는 이 장의 내용에 맞춰 직접 든 것이다_

○ **텍스트 분류와 토큰 분류** — 텍스트 분류는 문장 전체에 이름표 하나를 붙이고, 토큰 분류는 토큰마다 이름표를 붙인다. 9장의 이미지 분류와 의미 분할(픽셀마다 이름표)의 관계와 같다

### 3. 자연어 처리의 발전 과정

![자연어 처리의 발전 과정 연표](../practice/chapter10/results/fig10-3-nlp-history.png)

**그림 10.2** 자연어 처리는 사람이 규칙을 적는 방식에서, 데이터에서 횟수를 세는 방식, 신경망이 배우는 방식으로 바뀌었다. 연도의 출처는 각 항목의 각주에 있다

#### 3-1. 규칙 기반 — 사람이 규칙을 적는다

○ **조지타운-IBM 실험**(1954)[^georgetown]
  - 러시아어 문장 60여 개를 영어로 자동 번역해 보였다
  - 번역 프로그램에 든 것은 문법 규칙 6개와 어휘 250개였다

○ **ELIZA**(1966)[^eliza]
  - MIT의 요제프 바이첸바움(Joseph Weizenbaum)이 만든 대화 프로그램이다
  - 사용자가 쓴 문장에서 미리 정한 핵심 낱말을 찾고, 그 낱말에 딸린 응답 틀에 사용자의 말 일부를 끼워 넣어 답했다

○ **한계** — 언어의 모든 경우를 사람이 규칙으로 적을 수 없다. 규칙에 없는 문장이 들어오면 프로그램이 답하지 못한다

#### 3-2. 통계 기반 — 많은 문장에서 횟수를 센다

○ **생각의 전환** — 규칙을 적는 대신, 문장을 많이 모아 어떤 낱말이 어떤 결과와 함께 자주 나오는지 센다
  - 예: "코스피"가 든 제목이 경제 기사에 자주 나오면, "코스피"를 경제 쪽 근거로 쓴다
  - 문장을 숫자로 바꾸는 대표 방법이 단어 가방과 TF-IDF다(5절). 실습 10.2가 이 방법을 쓴다

○ **한계** — 낱말이 겹치지 않으면 관계를 알지 못한다. "배송"과 "택배"가 같은 것을 가리킨다는 정보가 숫자 어디에도 없다

#### 3-3. 신경망과 임베딩 — 낱말을 실수 벡터로 바꾼다

○ **word2vec**(2013)[^word2vec] — 주변 낱말로 가운데 낱말을 맞히거나 가운데 낱말로 주변 낱말을 맞히도록 작은 신경망을 학습시켜, 낱말마다 실수 벡터(임베딩)를 얻었다
  - 비슷한 자리에 나오는 낱말은 벡터도 비슷해진다. "배송"과 "택배"처럼 같은 낱말 옆에 자주 나오는 두 낱말은 서로 겹치지 않아도 가까워진다

○ **seq2seq**(2014)[^seq2seq] — 순환 신경망(RNN, 단어를 하나씩 순서대로 읽으며 앞 내용을 기억하는 신경망)이 문장 하나를 읽고 다른 문장 하나를 써낸다
  - 번역처럼 문장을 받아 문장을 내는 일을 신경망 하나로 처리했다

○ **한계** — 순환 신경망은 단어를 하나씩 차례로 읽으므로, 긴 문장에서는 앞 내용을 잊기 쉽고 계산을 나눠서 동시에 하기 어렵다

#### 3-4. 트랜스포머와 대규모 언어모델 — 먼저 크게 배우고 일에 맞춘다

○ **트랜스포머**(2017)[^transformer] — 문장 안의 모든 단어가 서로를 얼마나 참고할지(어텐션)를 한꺼번에 계산한다
  - 단어를 차례로 읽지 않으므로 계산을 동시에 할 수 있고, 먼 단어 사이의 관계도 바로 본다

○ **BERT**(2018)[^bert] — 큰 말뭉치에서 가려 둔 단어를 맞히며 먼저 학습(사전학습)한 뒤, 분류 같은 개별 작업에 맞춰 조금 더 학습(미세조정)한다

○ **GPT-3**(2020)[^gpt3] — 다음 단어를 예측하도록 크게 키운 언어모델이다. 따로 다시 학습하지 않고 프롬프트에 예시 몇 개만 넣어도 여러 작업을 했다

○ **ChatGPT**(2022년 11월)[^chatgpt] — 대규모 언어모델을 대화 형식으로 쓰게 한 서비스다. 다음 단어를 예측하는 원리와 그 한계는 11장에서 다룬다

#### 3-5. 한국어 자연어 처리

○ **형태소 분석이 먼저다** — 한국어는 낱말에 조사와 어미가 붙으므로, 문장을 뜻을 가진 가장 작은 단위인 **형태소**로 쪼개는 일이 앞단에 온다(4절)

○ **KLUE**(2021)[^klue] — 한국어 이해 능력을 평가하려고 만든 공개 과제 모음이다. 주제 분류를 포함한 8개 과제로 이루어지고, 실습 10.2의 데이터 YNAT가 그중 주제 분류 과제다

**표 10.2** 시기별 정리

| 시기 | 컴퓨터가 배우는 방식 | 대표 사례 | 남은 한계 |
|---|---|---|---|
| 규칙 기반 | 사람이 적은 규칙을 따른다 | 조지타운-IBM, ELIZA | 규칙에 없는 문장을 못 다룬다 |
| 통계 기반 | 낱말 횟수를 세어 확률로 판단한다 | 단어 가방, TF-IDF | 낱말이 안 겹치면 관계를 모른다 |
| 신경망·임베딩 | 낱말을 실수 벡터로 바꿔 배운다 | word2vec, seq2seq | 긴 문장을 차례로 읽기 어렵다 |
| 트랜스포머·대규모 언어모델 | 큰 말뭉치로 먼저 배우고 일에 맞춘다 | BERT, GPT-3, ChatGPT | 그럴듯하지만 틀린 문장을 쓴다(11장) |

### 4. 한국어 형태소 분석

○ **형태소**(morpheme) — 뜻을 가진 가장 작은 말의 단위
  - "배송이"는 "배송"(일반명사) + "이"(조사)로, "빨라요"는 "빠르"(형용사) + "어요"(어미)로 나뉜다

○ **형태소 분석기** — 문장을 형태소로 쪼개고 각 형태소에 품사를 붙이는 프로그램
  - 공백으로만 자르면 "배송이", "배송은", "배송도"가 서로 다른 단어 세 개가 된다
  - 형태소 분석기로 쪼개면 셋 다 "배송"이 남아 한 단어로 모인다

○ **Kiwi**[^kiwi] — 파이썬에서 `pip install kiwipiepy` 한 줄로 설치하는 한국어 형태소 분석기다(Apache-2.0 라이선스)

### 5. 문장을 숫자로 바꿔 분류하기

#### 5-1. 단어 가방과 TF-IDF

○ **단어 가방**(bag of words) — 사전의 단어마다 열을 하나씩 만들고, 문장에 그 단어가 몇 번 나왔는지 칸에 적는다
  - 행은 문장, 열은 단어다. 단어를 가방에 쏟아 담듯 순서는 버린다

![단어 가방 표의 생김새](../practice/chapter10/results/fig10-2-bag-of-words.png)

**그림 10.3** 초록 칸이 1, 회색 칸이 0이다. 한 문장은 단어 몇 개만 쓰므로 칸 대부분이 0이다

○ **TF-IDF** — 단어 가방의 칸 값을 고친다
  - 여러 문장에 흔히 나오는 단어의 값은 낮추고, 적은 문장에만 나오는 단어의 값은 높인다
  - 주제를 가르는 데 쓸모 있는 단어에 무게가 실린다

#### 5-2. 주제별로 단어에 가중치를 붙인다

○ **로지스틱 회귀로 분류한다**(4장)
  - 학습이 끝나면 주제마다, 단어마다 가중치가 하나씩 붙는다. 주제가 7개면 단어 하나에 가중치가 7개다
  - 새 제목이 들어오면 제목에 든 단어의 가중치를 주제별로 더하고, 합이 가장 큰 주제를 고른다
  - 사전에 없는 단어는 가중치가 없으므로 덧셈에서 빠진다

○ **실습 전에 세우는 예측**
  - 공백으로 자르면 "코스피가", "코스피는"이 다른 단어가 되어 같은 근거가 여러 칸으로 흩어진다
  - Kiwi로 쪼개면 "코스피" 한 칸에 모이므로 정확도가 오를 것이다

### 실습 10.2: 뉴스 제목 주제 분류

#### 실습 목표

- 뉴스 제목을 IT과학·경제·사회·생활문화·세계·스포츠·정치 7개 주제로 분류한다
- 공백으로 자른 경우와 Kiwi 형태소로 쪼갠 경우의 정확도를 비교한다
- 주제마다 판단을 좌우하는 단어와 자주 헷갈리는 주제를 찾는다

#### 데이터

- KLUE의 **YNAT**: 연합뉴스 기사 제목에 주제 하나를 붙인 공개 데이터다[^klue]. 훈련 세트 45,678개, 검증 세트 9,107개이고, 기사 날짜는 2016~2019년이다. 라이선스는 CC BY-SA 4.0이다[^ynat]
- 수업 시간 안에 끝나도록 훈련 세트에서 10,000개, 검증 세트에서 2,000개를 무작위로 뽑아 쓴다(seed 42)

#### 실행 명령과 핵심 코드

```bash
cd practice/chapter10/code
python 10-2-topic-classification.py
```

- 파일 맨 위의 `MY_HEADLINES`에 자기가 쓴 제목을 넣으면 5단계에서 주제를 맞혀 본다
- `analyzer=lambda tokens: tokens`는 이미 쪼갠 단어 목록을 그대로 쓰라는 설정이고, `min_df=2`는 두 번 이상 나온 단어만 사전에 넣으라는 설정이다

```python
vectorizer = TfidfVectorizer(analyzer=lambda tokens: tokens, min_df=2)
x_train = vectorizer.fit_transform(train_tokens)        # 쪼갠 제목 -> TF-IDF 표
model = LogisticRegression(max_iter=1000, random_state=RANDOM_SEED)
model.fit(x_train, y_train)
```

#### 결과 읽기

○ **예측이 맞았다: Kiwi로 쪼개면 정확도가 0.605에서 0.741로 올랐다**
  - 사전은 8,832개에서 7,225개로 줄었다. 조사만 다른 단어가 한 칸에 모였기 때문이다
  - "광합성하는"이 "광합성"으로, "인공세포"가 "인공"과 "세포"로 나뉘어, 다른 제목과 겹치는 단어가 늘었다

○ **기준선 0.097 — 제목을 읽지 않고 한 주제로만 찍었을 때의 정확도**
  - 기준선은 제목을 읽지 않고 모든 제목에 같은 주제 하나로 답하는 방법이다. 모델이 이보다 높아야 제목에서 무언가를 배웠다고 말할 수 있다
  - 찍을 주제는 훈련 데이터에서 가장 많은 주제로 정한다. 훈련 10,000개 중 세계가 1,846개로 가장 많으므로, 시험 제목 2,000개 전부에 "세계"라고 답한다

○ **주제를 가르는 단어는 사람이 봐도 납득된다**
  - 경제에는 "코스피", "금융", 스포츠에는 "류현진", "월드컵"이 올라왔다
  - "美", "中", "北", "朴"처럼 뉴스 제목에서 쓰는 한자 약칭이 세계·정치의 근거가 되었다. 2016~2019년 기사 제목에서 배운 단어이므로, 다른 시기의 제목에는 맞지 않을 수 있다

○ **사회 주제를 가장 많이 헷갈렸다**
  - 사회 794개 중 519개(0.654)만 맞혔고, 가장 많이 잘못 보낸 곳은 생활문화(63건)다
  - 사회 기사는 여러 주제의 낱말을 함께 쓴다. KLUE 논문도 제목만으로는 주제를 정확히 가리기 어려운 경우가 많아, 여러 사람이 합의한 제목만 남겼다고 적었다[^klue]

○ **내가 쓴 제목** — "올여름 바닷가 피서객 작년보다 늘어"는 경제 0.31, 생활문화 0.25로 두 주제 사이에서 갈렸다. 확률이 낮으면 모델이 확신하지 못한 것이다
