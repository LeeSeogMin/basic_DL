# 10주차 계획서 — 텍스트와 임베딩: 문장을 숫자로 바꾸기

## 1. 장의 역할

10주차는 컴퓨터가 텍스트를 직접 이해하지 못한다는 사실에서 출발한다. 학생은 문장을 숫자로 바꾸는 과정(토큰화, 벡터화, 임베딩)을 직접 실습하며, 텍스트 분류와 감성 분석의 기본 흐름을 경험한다.

이 장은 9주차(이미지 인식)와 대비된다. 이미지는 픽셀이라는 숫자 배열로 이미 존재하지만, 텍스트는 문자열이므로 숫자로 변환하는 단계가 반드시 필요하다. 이 변환 과정에서 정보가 빠지거나 편향이 들어올 수 있다는 점도 함께 다룬다.

수학적 엄밀함보다 직관을 우선한다. 다만 용어는 학술적으로 정확하게 사용한다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. 컴퓨터가 텍스트를 직접 처리하지 못하는 이유를 설명한다.
2. 토큰화가 무엇인지 설명하고, 같은 문장이 토큰화 방식에 따라 다르게 나뉘는 예를 든다.
3. Bag-of-Words와 TF-IDF의 차이를 자기 말로 설명한다.
4. 임베딩의 직관(비슷한 뜻의 단어가 가까운 벡터가 된다)을 설명한다.
5. 감성 분류기를 실행하고 정확도와 혼동행렬을 해석한다.
6. 모델이 헷갈린 문장을 찾고 왜 헷갈렸는지 추측한다.
7. 텍스트 데이터의 편향이 모델 결과에 어떤 영향을 주는지 설명한다.

## 3. 절 구성

| 절 | 제목 | 핵심 내용 | 산출물 |
|---|---|---|---|
| 10.1 | 컴퓨터는 글자를 모른다 | 텍스트가 왜 숫자가 아닌지, 변환이 필요한 이유 | 비교 설명 |
| 10.2 | 토큰화: 문장을 조각으로 나누기 | 띄어쓰기, 형태소, 서브워드 토큰화 비교 | 토큰화 예시표 |
| 10.3 | 벡터화: 단어 조각을 숫자로 바꾸기 | Bag-of-Words, TF-IDF | 벡터 비교표 |
| 10.4 | 임베딩의 직관 | 비슷한 뜻의 단어가 가까운 벡터가 된다 | 직관 설명 |
| 10.5 | 감성 분석: 문장이 긍정인지 부정인지 | 텍스트 분류의 대표 사례 | 분류 흐름도 |
| 10.6 | 실습: 텍스트 감성 분류기 | CountVectorizer/TF-IDF + LogisticRegression | 실행 로그, 결과 파일 |
| 10.7 | 모델이 헷갈린 문장 분석 | 틀린 문장 5개를 찾고 원인을 추측 | 헷갈린 문장 표 |
| 10.8 | AI 활용: 학습용 문장 생성과 편향 분석 | AI가 만든 문장의 편향 가능성 | 편향 분석 메모 |
| 10.9 | 책임 있는 AI 체크 | 텍스트 데이터 편향, 감성 분류의 한계 | 체크리스트 |

## 4. 실습 설계

### 실습 파일

- `practice/chapter10/code/10-1-text-classifier.py`

### 실습 내용

1. 한국어/영어 짧은 리뷰 문장 약 30개를 코드 안에 직접 정의한다(합성 데이터).
2. CountVectorizer로 Bag-of-Words 벡터를 만든다.
3. TfidfVectorizer로 TF-IDF 벡터를 만든다.
4. 각각 LogisticRegression으로 감성 분류 모델을 학습시킨다.
5. 테스트 정확도와 혼동행렬을 출력한다.
6. 모델이 헷갈린(틀린) 문장 5개를 찾아 출력한다.
7. 결과를 CSV와 PNG로 저장한다.

### 예상 결과 파일

- `practice/chapter10/results/10-1-text-classifier.log`
- `practice/chapter10/results/10-1-text-classifier.evidence.json`
- `practice/chapter10/results/confusion_matrix.png`
- `practice/chapter10/results/confused_sentences.csv`

## 5. 책임 있는 AI 체크

학생은 다음을 점검한다.

| 점검 항목 | 질문 |
|---|---|
| 데이터 편향 | 훈련 데이터에 특정 표현이나 주제가 편중되어 있지 않은가 |
| 감성 분류 한계 | 반어, 비꼼, 맥락 의존 표현을 모델이 구분할 수 있는가 |
| AI 생성 데이터 | AI가 만든 학습용 문장이 특정 방향으로 편향되어 있지 않은가 |
| 실행 결과 일치 | 본문의 수치가 실행 로그와 일치하는가 |
| 과장 표현 | 모델 성능을 과대평가하지 않았는가 |

4. AI로 생성한 문장의 편향 분석 메모
5. 책임 있는 AI 체크리스트
6. "텍스트 데이터의 편향이 모델에 어떤 영향을 주는가"에 대한 5문장 설명
