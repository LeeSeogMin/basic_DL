# 8주차 계획서 — 중간 미니 프로젝트: 1~7장을 하나로 잇는다

## 1. 주차의 성격

8주차는 교재 장이 아니다. 새 이론이 없고 정해진 실습 코드도 없다. `강의계획서.md`의 평가 항목 중 **중간 고사(20%)**가 이 프로젝트다. 주차별 계획 표에서 8주차의 "교재 장" 칸이 비어 있는 것도 같은 이유다.

앞선 일곱 주 동안 학생은 이미 만들어진 코드를 받아 값을 바꿔 보는 방식으로 실습했다. 여기서는 무엇을 풀지부터 학생이 정한다. 안내 문서는 `docs/ch8.md`에 둔다.

대상은 학부 2학년이다. 1차시는 프로젝트 설계, 2차시는 제작과 발표다.

## 2. 학습 목표

1. 풀 문제를 스스로 정하고, 그 문제가 분류인지 회귀인지 가른다
2. 데이터를 준비하고 특성과 라벨을 구분한다
3. 기준선을 먼저 만들고, 그 위에서 모델을 비교한다
4. 훈련 성적과 테스트 성적을 함께 재서 과적합 여부를 확인한다
5. 모델이 틀린 사례를 찾아 왜 틀렸는지 설명한다

## 3. 1차시 절 구성

| 절 | 제목 | 핵심 내용 | 시각 자료 |
|---|---|---|---|
| 1 | 지난 일곱 주에서 무엇을 가져오는가 | 3~7장과 프로젝트 칸의 대응. 못 채우는 칸이 약한 자리다 | 표 8.1 |
| 2 | 주제를 고르는 두 가지 기준 | 1장의 두 질문을 자기 주제에 댄다. 유형과 피할 주제 | 표 8.2 |
| 3 | 계획서 한 장 | 문제·데이터·라벨·기준선·모델·평가·난관·AI 도구 | — |
| 4 | 실패를 숨기지 않는다 | 채점이 갈리는 지점. 4장 실습 4.1의 경계선 오류와 연결 | 표 8.3 |

○ 개념 그림을 새로 만들지 않는다. 1~7장의 그림을 다시 쓴다.

## 4. 2차시 제작 설계

정해진 실습 코드가 없다. 학생이 앞선 장의 코드를 가져다 고친다.

- 패키지: `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `scipy`. 새 패키지를 설치하지 않는다
- 데이터: 직접 만든 표, 공개 데이터, 또는 `make_classification`·`make_moons`·`make_circles`
- 제작 순서 여덟 단계를 `docs/ch8.md`에 둔다. 4단계(기준선 측정)를 건너뛰지 못하게 한다
- 발표는 3분. 담을 항목 일곱 가지를 표로 고정한다

○ **교수자가 확인할 지점**

  - 주제 확정 단계에서 "정답을 라벨로 붙일 수 있는가"를 묻는다
  - 기준선 값을 재기 전에 모델을 돌리는 학생을 되돌린다
  - GPU가 필요한 주제, 데이터를 구할 수 없는 주제를 초기에 걸러낸다

## 5. 실행 증거

이 주차에는 `scripts/run_and_capture.py` 게이트를 적용하지 않는다. 저장소에 넣을 실습 코드가 없기 때문이다.

학생 제출물에는 실행 화면이 들어간다. 화면에 기준선·훈련 정확도·테스트 정확도·혼동행렬이 함께 보여야 한다.

## 6. 외부 시각 자료

새로 넣지 않는다. 4장(기준선·혼동행렬)과 7장(과적합)의 자료를 다시 안내한다.
