# 8주차 계획서 — 중간 미니 프로젝트: 나의 첫 AI 모델

## 1. 장의 역할

8주차는 1~7주차에서 배운 개념(데이터, 머신러닝, 신경망, 학습, 과적합)을 하나의 작은 프로젝트로 연결하는 통합 경험이다. 새로운 이론을 추가하지 않고, 기존 개념을 직접 적용하고 실패를 분석하는 데 초점을 둔다.

## 2. 학습 목표

1. 문제 정의부터 데이터 준비, 모델 선택, 학습, 평가까지 한 흐름으로 수행한다.
2. 모델이 잘하는 것과 못하는 것을 구분해 설명한다.
3. AI 코딩 도구 사용 과정을 기록하고, 직접 검증한 부분을 명시한다.
4. 실패 사례를 숨기지 않고 분석한다.

## 3. 절 구성 (1교시/2교시 배분)

| 절 | 교시 | 제목 | 핵심 내용 |
|---|---|---|---|
| 8.1 | 1교시 | 프로젝트란 무엇인가 | 과제와 프로젝트의 차이, 이번 프로젝트의 범위 |
| 8.2 | 1교시 | 주제 선택과 계획 세우기 | 프로젝트 유형 소개, 계획 양식, 좋은 주제의 조건 |
| 8.3 | 1교시 | 체크리스트: 무엇이 있어야 하는가 | 필수 제출물, 평가 기준, 실패 사례의 가치 |
| 8.4 | 2교시 | 프로젝트 착수 | 주제 확정, 데이터 준비, 코드 시작 |
| 8.5 | 2교시 | 중간 점검과 디버깅 | 실행 여부 확인, 오류 해결, AI 활용 기록 |
| 8.6 | 2교시 | 발표 준비 | 3분 발표 구성, 실패 사례 포함 |

## 4. 실습 설계

### 코드
8주차 전용 실습 코드는 없다. 학생이 1~7주차 코드를 기반으로 자기 프로젝트를 만든다.

### 프로젝트 유형 (contents.md 기준)
1. 간단한 취향 분류기 (3주차 데이터 확장)
2. 작은 이미지 분류기 (9주차 미리보기)
3. 댓글 긍정/부정 분류기
4. 학생이 만든 표 데이터 기반 예측기

### 권장 흐름
문제 정의 → 데이터 수집/생성 → 모델 선택 → 학습 → 평가 → 실패 분석 → 발표

## 5. 제출물

1. 실행 코드 (GitHub 또는 Colab 링크)
2. 결과 화면 또는 실행 로그
3. 실패 사례 3개
4. AI 사용 로그 (프롬프트, 수정, 검증)
5. 책임 있는 AI 체크리스트
6. 3분 발표 자료

## 6. 책임 있는 AI 체크

| 항목 | 확인 |
|---|---|
| 모델 성능을 과장하지 않았다 |  |
| 실패 사례를 숨기지 않고 기록했다 |  |
| AI가 만든 코드를 이해하고 직접 실행했다 |  |
| 데이터에 개인정보가 포함되지 않았다 |  |
| 출처 없는 수치나 설명을 사용하지 않았다 |  |

## 7. 평가 초점

정확도보다 과정과 해석을 본다. 모델이 완벽하지 않아도, 왜 틀렸는지 설명하면 좋은 프로젝트다.
