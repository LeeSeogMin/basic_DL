# 9주차 계획서 — 이미지 인식과 CNN: 컴퓨터가 이미지를 보는 방식

## 1. 장의 역할

9주차는 "컴퓨터에게 이미지란 무엇인가"를 학생이 처음으로 구체적으로 경험하는 장이다. 학생은 이미지가 픽셀값의 숫자 배열이라는 사실을 확인하고, 합성곱 연산이 이미지에서 특징을 찾는 과정을 직관적으로 이해한다. 실습에서는 작은 이미지 분류기를 만들고, 모델이 틀린 이미지를 모아 "실패 갤러리"를 만든다.

이 장은 CNN의 수학적 유도보다 직관을 우선한다. 다만 용어는 학술적으로 정확하게 사용한다. 모든 개념은 학생이 눈으로 볼 수 있는 픽셀, 필터, 특징 맵, 틀린 이미지와 연결한다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. 이미지가 픽셀값의 숫자 배열이라는 것을 설명한다.
2. 채널의 의미를 설명한다 (흑백 1채널, 컬러 3채널).
3. 합성곱 연산이 필터로 이미지에서 특징을 찾는 과정이라고 설명한다.
4. 풀링이 특징 맵의 크기를 줄이는 역할을 한다고 설명한다.
5. CNN의 기본 구조(합성곱-풀링-완전연결)를 말한다.
6. 작은 이미지 분류기를 실행하고 결과를 해석한다.
7. 모델이 틀린 이미지를 실패 갤러리로 만들어 분석한다.

## 4. 실습 설계

### 실습 파일

- `practice/chapter9/code/9-1-image-classifier.py`

### 실습 내용

1. sklearn의 load_digits 데이터(8x8 흑백 숫자 이미지)를 불러온다.
2. 이미지 몇 개를 시각화해 픽셀값을 확인한다.
3. 데이터를 훈련 데이터와 테스트 데이터로 나눈다.
4. 기준선 모델(최빈 클래스)과 MLP 분류기를 비교한다.
5. 테스트 정확도와 혼동행렬을 출력한다.
6. 모델이 틀린 이미지를 모아 실패 갤러리 PNG로 저장한다.
7. 혼동행렬 그림을 저장한다.

### 설계 판단

- **torch 대신 sklearn**: requirements.txt에 torch가 없다. sklearn의 MLPClassifier로 이미지 분류를 수행한다. CNN 원리는 강의에서 설명하고, 실습은 "이미지를 숫자로 다루고 분류하는 경험"에 집중한다.
- **load_digits**: 8x8 크기, 1,797장, CPU 즉시 실행 가능하다. MNIST(28x28)보다 가볍고 다운로드가 필요 없다.
- **실패 갤러리**: 틀린 이미지를 시각화해 PNG로 저장한다. 4주차의 틀린 사례 CSV와 같은 취지이지만, 이미지는 눈으로 직접 볼 수 있어 더 직관적이다.

## 5. 책임 있는 AI 체크

학생은 AI에게 CNN 구조를 제안받을 수 있다. 단, 다음을 확인해야 한다.

| 점검 항목 | 질문 |
|---|---|
| 정확도 과장 | AI가 정확도 하나만 보고 좋은 모델이라고 단정했는가 |
| 혼동행렬 해석 | AI가 어떤 숫자를 어떤 숫자로 많이 틀렸는지 설명했는가 |
| 실패 갤러리 | 모델이 틀린 이미지를 숨기지 않고 보여주었는가 |
| 이미지 데이터 편향 | 학습 데이터의 숫자 분포가 고르지 않으면 결과에 영향을 줄 수 있다 |
| CNN 구조 과잉 | AI가 제안한 CNN 구조가 수업용으로 너무 무거운지 따져보았는가 |
