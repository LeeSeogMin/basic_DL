# 3주차 계획서 — Python과 데이터: AI에게 먹일 재료 만들기

## 1. 장의 역할

3주차는 모델을 만들기 전 단계다. 학생이 자기 손으로 표를 만들고, 그 표의 어느 열이 입력이고 어느 열이 정답인지 정하고, 표가 망가지는 네 가지 모습을 직접 고친다. 4주차에서 그 표를 모델에게 넘긴다.

Python 문법을 처음부터 가르치지 않는다. 변수, 리스트, 딕셔너리는 표를 만드는 데 필요한 만큼만 다루고, 세 그릇이 같은 내용을 담는다는 대응 관계를 그림으로 확인한다.

수치를 말로 설명하지 않는다. 결측을 0으로 채우면 평균이 얼마나 어긋나는지, 흠집을 몇 건 찾아 몇 건 고쳤는지를 학생이 실행 결과의 숫자로 본다.

대상은 학부 2학년이다. 1차시 이론 강의, 2차시 실습으로 나눠 진행한다.

## 2. 학습 목표

1. 표 한 장에서 행과 열이 각각 무엇을 뜻하는지 설명한다.
2. 리스트와 딕셔너리로 적은 내용을 표로 옮긴다.
3. 표의 어느 열이 특성이고 어느 열이 라벨인지 정한다.
4. 결측값, 중복 행, 이상치, 잘못된 자료형을 찾아 센다.
5. 결측을 0으로 채우면 평균이 어긋나는 정도를 숫자로 말한다.
6. 자기가 만든 표에 개인정보를 넣지 않는다.

## 3. 1차시 이론 절 구성

| 절 | 제목 | 핵심 내용 | 시각 자료 |
|---|---|---|---|
| 1 | 데이터를 표로 본다 | 행 = 데이터 한 건, 열 = 재고 싶은 항목 | 표 3.1 |
| 2 | 변수, 리스트, 딕셔너리 | 같은 내용을 담는 세 그릇, 리스트 두 개의 순서 어긋남 | 그림 3.1 |
| 3 | 특성과 라벨 | 라벨은 표가 정하지 않고 질문이 정한다, 훈련/테스트 예고 | 그림 3.2, 표 3.2 |
| 4 | 좋은 데이터와 나쁜 데이터 | 결측·중복·이상치·자료형 네 가지 | 그림 3.3 |
| 5 | 결측을 0으로 채우면 생기는 일 | 0은 "없음"이 아니라 "0시간"이다 | 실습 3.2 수치 |
| 6 | 개인정보가 들어가면 안 되는 이유 | 별명만 쓴다, 삭제해도 되돌릴 수 없다 | 표 3.3 |
| 7 | 직접 움직여 보는 웹 자료 | 외부 시각 자료 4건 | 링크 표 |

## 4. 2차시 실습 설계

실습은 두 개다. 각각 노트북에서 몇 초 안에 끝난다. GPU가 필요 없다.

### 실습 3.1 — 내 관심사를 표로 만든다

- 파일: `practice/chapter3/code/3-1-my-data.py`
- 데이터: 학생이 직접 채우는 관심사 목록(음식·영화·운동). 기본값은 예시 10개다
- 학생 조작 지점: 파일 상단의 `NICKNAME`, `FAVORITE_FOODS`, `FAVORITE_MOVIES`, `FAVORITE_SPORTS`, `LIKE_THRESHOLD`
- 흐름: 리스트 → 딕셔너리 → 표 → CSV 저장 → 다시 읽기 → 특성·라벨 정하기 → 훈련/테스트 분할 → 그림
- 성취 지점: 리스트 값을 바꾸면 표와 그림이 함께 바뀐다
- 산출물: `results/week03-my-data.csv`, `results/my-interests.png`
- 개인정보 주의를 코드 docstring과 실행 첫 줄 양쪽에 넣는다

### 실습 3.2 — 흠집 난 표를 고친다

- 파일: `practice/chapter3/code/3-2-data-quality.py`
- 데이터: 합성 설문 표 60행에 흠집 26건을 일부러 낸다(중복 4, 문자열 숫자 6, 범위 이탈 3, 특성 결측 10, 라벨 결측 3)
- 학생 조작 지점: 파일 상단의 흠집 개수 다섯 개와 `FILL_STRATEGY`
- 회계 규칙: 흠집을 서로 겹치지 않는 행에 넣고, 중복 → 문자열 → 이상치 → 결측 순서로 처리한다. 찾음 = 고침 + 남음을 코드가 `assert`로 확인한다
- 교훈 지점 1: 라벨의 빈 칸은 채우지 않는다. 정답을 지어내는 것이기 때문이다. 그래서 3건이 남는다
- 교훈 지점 2: 결측을 0으로 채운 평균을 흠집 내기 전 참값과 대조한다
- 산출물: `results/data-cleaning-before-after.png`, `results/week03-dirty.csv`, `results/week03-cleaned.csv`, `results/week03-quality-report.csv`
