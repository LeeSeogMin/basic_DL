# 3주차 계획서 — Python과 데이터: AI에게 먹일 재료 만들기

## 1. 장의 역할

3주차는 딥러닝 모델에 들어가는 재료, 즉 데이터의 구조와 역할을 처음으로 다루는 장이다. 학생은 Python 기초 문법(변수, 리스트, 딕셔너리)을 간단히 익히고, 표 형태의 데이터를 직접 만들고, 특성(feature)과 라벨(label)을 구분하고, 훈련 데이터와 테스트 데이터의 개념을 이해한다.

이 장의 실습은 학생 자신의 관심사(영화, 음식, 노래, 운동, 게임 취향)를 작은 표로 만들고 간단한 규칙 기반 추천을 구현하는 것이다. 이후 "AI가 이 규칙을 배운다면 어떤 데이터가 필요할까"를 토론한다. 이 흐름은 4주차에서 모델이 데이터로부터 규칙을 배우는 방식(머신러닝)으로 자연스럽게 연결된다.

이 장은 다음 원칙을 따른다.

- Python 문법은 이 장에서 필요한 최소 범위(변수, 리스트, 딕셔너리, for, if)만 다룬다.
- 데이터는 합성 데이터를 사용하되, 학생이 자기 데이터를 넣을 수 있는 구조를 제공한다.
- 데이터에 개인정보가 들어가지 않도록 2주차에서 형성한 안전 습관을 반복한다.
- 4주차에서 사용할 훈련/테스트 분할 개념을 먼저 소개하되, 실제 모델 학습은 4주차로 넘긴다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. Python에서 변수, 리스트, 딕셔너리를 만들고 값을 꺼낸다.
2. 표 데이터의 행, 열, 셀의 의미를 설명한다.
3. 특성(feature)과 라벨(label)을 구분한다.
4. 훈련 데이터와 테스트 데이터를 나누는 이유를 말한다.
5. 좋은 데이터와 나쁜 데이터의 차이를 예로 들어 설명한다.
6. CSV 파일을 만들고 읽는 Python 코드를 실행한다.
7. 데이터를 간단한 그래프로 시각화한다.
8. 데이터에 개인정보가 포함되지 않았는지 확인한다.

## 4. 실습 설계

### 실습 파일

- `practice/chapter3/code/3-1-my-data-plot.py`

### 실습 내용

1. 합성 학생 관심사 데이터를 만든다 (이름은 가명, 개인정보 없음).
2. 영화/음식/노래/운동/게임 취향을 1~5 점수로 표현한 표를 CSV로 저장한다.
3. 규칙 기반으로 간단한 추천을 구현한다 (예: "영화 점수와 게임 점수가 모두 4 이상이면 'SF 팬'으로 분류").
4. 데이터를 막대그래프로 시각화해 PNG로 저장한다.
5. 데이터 품질 체크리스트(결측값 수, 범위 확인 등)를 출력한다.

## 6. 책임 있는 AI 체크

학생은 제출 전 다음 항목을 확인한다.

| 항목 | 확인 |
|---|---|
| 데이터에 실제 개인정보(이름, 학번, 연락처)가 들어가지 않았다 |  |
| 합성 데이터임을 명시했다 |  |
| AI가 만든 코드가 어떤 파일을 읽고 쓰는지 설명할 수 있다 |  |
| AI가 만든 코드를 직접 실행했다 |  |
| 코드가 파일 삭제나 외부 전송을 하지 않는지 확인했다 |  |
| 이해하지 못한 코드는 이해하지 못했다고 표시했다 |  |

## 7. 수업 운영 리스크

| 리스크 | 대응 |
|---|---|
| Python 기초가 부족한 학생 | 변수, 리스트, 딕셔너리의 최소 예제만 다루고, AI 도구로 문법 질문 허용 |
