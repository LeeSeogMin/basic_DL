# 14주차 계획서 — 기말 프로젝트 제작 워크숍

## 1. 장의 역할

14주차는 기말 프로젝트를 실제로 착수하고 중간 결과를 만드는 워크숍이다. 8주차(중간 미니 프로젝트)와 비슷한 구조이지만, 1~13주차 전체를 포괄하며 프로젝트 규모와 평가 기준이 다르다.

새로운 이론을 추가하지 않는다. 대신 프로젝트 계획, 디버깅, AI 활용, 위험 점검을 수업 시간 안에 진행한다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. 기말 프로젝트 주제를 확정하고 계획서를 작성한다.
2. 수업 시간 안에 최소한 실행 가능한 중간 결과를 만든다.
3. 프로젝트의 위험 요소를 점검한다.
4. 15주차 발표에 필요한 구성 요소를 정리한다.

## 3. 절 구성

| 절 | 교시 | 제목 | 핵심 내용 |
|---|---|---|---|
| 14.1 | 1교시 | 기말 프로젝트 기준 | 필수 요건, 평가 기준, 피해야 할 프로젝트 |
| 14.2 | 1교시 | 프로젝트 유형 | 권장 유형과 예시 |
| 14.3 | 1교시 | 발표 구성 | 15주차 발표에 포함할 요소 |
| 14.4 | 2교시 | 프로젝트 착수 | 주제 확정, 데이터 준비, 코드 시작 |
| 14.5 | 2교시 | 디버깅과 중간 점검 | 실행 여부 확인, 오류 해결 |
| 14.6 | 2교시 | 위험 점검 | 개인정보, 보안, 편향, 성능 과장, AI 의존성 |

## 4. 실습 설계

### 코드

14주차 전용 실습 코드는 없다. 학생이 1~13주차 코드를 기반으로 기말 프로젝트를 만든다.

### 권장 흐름

문제 정의 -> 데이터 준비 -> 모델 선택 -> 학습 -> 평가 -> 데모 또는 시각화 -> 실패 분석 -> 위험 점검 -> 발표 초안

## 5. 책임 있는 AI 체크

| 점검 항목 | 질문 |
|---|---|
| 성능 과장 | 정확도만 보고 모델이 좋다고 단정하지 않았는가 |
| 실패 기록 | 모델이 틀린 사례를 최소 3개 기록했는가 |
| 과적합 확인 | 훈련 정확도와 테스트 정확도를 함께 확인했는가 |
| AI 기록 | AI 도구 사용 과정을 프롬프트와 함께 기록했는가 |
| 개인정보 | 데이터에 실제 개인정보가 포함되지 않았는가 |
| 보안 | 코드에 파일 삭제, 외부 전송, 비밀키 노출 위험이 없는가 |
| 모델 한계 | 모델의 한계를 설명했는가 |

## 6. 제출물

1. 프로젝트 계획서
2. 실행 가능한 중간 결과 (코드 + 실행 로그)
3. 발표 초안
4. 위험 점검표
5. AI 사용 로그
