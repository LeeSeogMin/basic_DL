# 4주차 계획서 — 머신러닝 첫걸음: 규칙을 쓰지 않고 분류하기

## 1. 장의 역할

4주차는 딥러닝으로 들어가기 전, "모델이 데이터에서 배운다"는 생각을 학생이 처음으로 구체적으로 경험하는 장이다. 학생은 사람이 규칙을 직접 쓰는 방식과 모델이 데이터에서 판단 경계를 찾는 방식의 차이를 2차원 점 분류 실습으로 확인한다.

이 장은 수학적 엄밀함보다 직관을 우선한다. 다만 용어는 학술적으로 정확하게 사용한다. 모든 개념은 학생이 눈으로 볼 수 있는 점, 색, 선, 표, 오류 사례와 연결한다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. 규칙 기반 방식과 머신러닝 방식의 차이를 설명한다.
2. 분류와 회귀의 차이를 구체적 예로 구분한다.
3. 훈련 데이터와 테스트 데이터를 나누는 이유를 설명한다.
4. 기준선 모델의 의미를 설명한다.
5. 정확도만 보고 모델을 평가하면 위험한 이유를 말한다.
6. 혼동행렬을 보고 어떤 종류의 오류가 많은지 해석한다.
7. 모델이 틀린 사례를 숨기지 않고 분석한다.

## 4. 실습 설계

### 실습 파일

- `practice/chapter4/code/4-1-simple-classifier.py`

### 실습 내용

1. 2차원 점 데이터를 만든다.
2. 각 점을 A그룹 또는 B그룹으로 표시한다.
3. 데이터를 훈련 데이터와 테스트 데이터로 나눈다.
4. 기준선 모델과 로지스틱 회귀 모델을 비교한다.
5. 테스트 정확도와 혼동행렬을 출력한다.
6. 모델이 틀린 사례 일부를 출력한다.
7. 산점도와 판단 경계 그림을 저장한다.
8. 혼동행렬 그림을 저장한다.

## 5. 책임 있는 AI 체크

학생은 AI에게 모델 결과 해석을 맡길 수 있다. 단, 다음을 확인해야 한다.

| 점검 항목 | 질문 |
|---|---|
| 정확도 과장 | AI가 정확도 하나만 보고 좋은 모델이라고 단정했는가 |
| 혼동행렬 해석 | AI가 어떤 오류가 많은지 표와 맞게 설명했는가 |
| 틀린 사례 | AI가 모델이 틀린 사례를 숨기지 않았는가 |
| 실행 결과 일치 | AI 설명이 내가 실행한 로그와 일치하는가 |
| 책임 표현 | AI가 "항상", "완벽히", "명백히" 같은 과장 표현을 쓰지 않았는가 |
