# 1주차 계획서 — AI와 딥러닝은 무엇인가

## 1. 장의 역할

1주차는 한 학기의 첫 시간이다. 학생 대부분은 이미 대화형 AI를 쓴다. 그래서 이 장의 목적은 AI를 처음 소개하는 데 있지 않고, 이미 쓰고 있는 도구가 어떤 종류의 물건인지 이름을 정확히 붙이는 데 있다.

인공지능·머신러닝·딥러닝·생성형 AI 네 낱말의 포함 관계를 그림 한 장으로 정리하고, 지금 AI가 잘하는 일과 못하는 일을 가르는 기준 두 개를 세운다. 마지막에 앞으로 15주 동안 무엇을 만드는지 미리 보여 준다.

수학과 코드를 쓰지 않는다. 학생 노트북에 아직 Python이 없기 때문이다. 개발환경은 2주차에 만든다.

대상은 학부 2학년이다. 1차시 이론 강의, 2차시 실습으로 나눠 진행한다.

## 2. 학습 목표

1. 인공지능·머신러닝·딥러닝·생성형 AI의 포함 관계를 그림으로 그려 설명한다.
2. 규칙을 사람이 쓰는 방식과 데이터에서 찾는 방식의 차이를 자기 말로 말한다.
3. 어떤 일을 AI에게 맡길지 두 가지 기준으로 따진다.
4. 이미지 분류기를 직접 만들어 보고, 잘 맞히는 경우와 틀리는 경우를 찾는다.
5. 대화형 AI의 답에서 확인이 필요한 부분을 갈라낸다.

## 4. 2차시 실습 설계

이 장만의 조건이 하나 있다. **학생 노트북에 아직 Python이 없다.** 개발환경 설치는 2주차 과제다. 그래서 1주차 실습 두 개는 브라우저만으로 한다. 설치·터미널·코드 실행을 요구하지 않는다.

실습용 파이썬 코드를 만들지 않는다. `practice/chapter1/code/`에는 이론용 개념 그림 스크립트 하나만 둔다.

### 실습 1.1 — 코드 없이 이미지 분류기 만들기

- 도구: Google Teachable Machine (`https://teachablemachine.withgoogle.com/`)
- 하는 일: 이미지 프로젝트를 열어 클래스 두세 개를 만들고, 웹캠으로 자세나 물건을 찍어 학습시킨다
- 확인 지점: 학습이 끝난 뒤 잘 맞히는 경우와 틀리는 경우를 찾는다. 배경·조명·거리를 바꿔 일부러 틀리게 만든다
- 성취 지점: 코드 한 줄 없이 자기 손으로 모델을 만들고, 그 모델이 틀리는 조건을 스스로 찾아낸다
- 산출물: 미리보기 화면 캡처 1장
- 설치·로그인이 필요 없다. 데스크톱 Chrome 또는 Safari가 필요하다
- 개인정보: Google Drive에 저장하지 않는 한 샘플은 서버로 가지 않는다(FAQ 확인). 얼굴 대신 물건을 찍어도 된다고 안내한다

### 실습 1.2 — 같은 질문, 두 가지 방식

- 도구: ChatGPT · Claude · Gemini 중 하나
- 하는 일: 같은 주제를 두 방식으로 묻는다. ① 한 줄 질문 ② 조건을 붙인 질문(대상·길이·예시·모를 때의 처리)
- 확인 지점: 두 답을 표에 옮기고, 잘한 답과 확인이 필요한 답을 나눠 적는다
- 성취 지점: 프롬프트를 바꾸면 답이 달라진다는 것을 자기 눈으로 본다. 11주차 환각 실습의 예고편이 된다
- 산출물: 두 답을 나란히 띄운 화면 캡처 1장
- 개인정보: 이름·학번·연락처를 프롬프트에 넣지 않는다고 못 박는다
