# 12주차 계획서 — AI 코딩 에이전트와 책임 있는 자동화

## 1. 장의 역할

12주차는 코딩 에이전트에게 일을 맡길 때 **사람이 하는 세 가지 일**을 다룬다. 맡기기 전에 범위를 좁히고(명세·권한), 맡긴 뒤에 기록을 읽고(보고와 기록의 대조), 틀렸으면 되돌린다(저장 지점). 11주차에서 생성형 AI의 문장을 검증했다면, 이번 장의 검증 대상은 에이전트가 실행한 명령이다.

AI 도구는 학생이 수업 중 직접 쓴다. 이 장의 실습 코드는 AI를 호출하지 않고 인터넷도 쓰지 않는다. 실습의 명령 목록·작업 목록·보고는 사람이 적은 합성 예제다.

대상은 학부 2학년이다. 2026년 11월 개정에서 최신 제품 문서와 2026년 설문·국내 지침을 반영했고, 실습 두 개를 교체했다. 분량은 PDF 20쪽 이하로 둔다.

## 2. 학습 목표

1. 코딩 에이전트와 자동완성이 맡는 범위 차이를 설명한다.
2. 지시문을 입력·출력·금지·실패 네 칸의 명세로 쓴다.
3. 권한 설정 세 단계를 구분하고, 규칙 파일의 문장과 권한 설정의 차이를 말한다.
4. 에이전트의 보고와 파일에서 계산한 기록을 대조하고, 저장 지점으로 되돌린다.
5. AI 도구에 넣지 말아야 할 자료를 구분하고, 결과의 책임이 누구에게 있는지 말한다.

## 4. 실습 설계

실습은 두 개다. 각각 노트북에서 몇 초 안에 끝난다. pandas·matplotlib만 쓴다.

### 실습 12.1 — 같은 명령 12개를 권한 설정 셋으로 판정한다

- 파일: `practice/chapter12/code/12-1-permission-check.py`
- 입력: 코드 안에 적은 합성 명령 12개(읽기 3, 쓰기 4, 삭제 3, 전송 1, 설치 1). 작업 폴더는 이 수업 저장소 `basic_DL`이며 1·2·5·6·7번의 대상은 저장소에 실제로 있는 파일이다. 명령은 실행하지 않고 판정만 한다
- 동작: 권한 설정 셋(읽기 전용 / 작업 폴더 쓰기 / 전부 허용)마다 바로 실행·사람에게 묻기·차단으로 판정한다
- 학생 조작 지점: `WORKSPACE`, `NETWORK_ALLOWED`, `COMMANDS`
- 교훈 지점: 설정을 넓히면 사람에게 묻는 횟수가 줄고 확인 없이 실행되는 위험 명령 수가 늘어난다. 작업 폴더 안의 본문 원본 덮어쓰기는 가운데 설정에서도 통과한다
- 산출물: `results/permission_report.png`, `results/permission_table.csv`

### 실습 12.2 — 에이전트의 보고와 실제 변경을 대조하고 되돌린다

- 파일: `practice/chapter12/code/12-2-report-vs-record.py`
- 입력: `practice/chapter12/sample_folder/`(합성 예제 폴더, 파일 11개), 코드 안에 적은 합성 작업 목록 5건과 합성 보고 4건
- 동작: 폴더를 임시 폴더에 복사해 저장 지점을 만들고, 작업 목록을 복사본에 적용한 뒤, 전후 해시를 비교해 실제 변경 목록을 계산한다. 보고와 대조하고 저장 지점으로 되돌려 해시가 같은지 확인한다
- 안전 규칙: 원본 `sample_folder`는 건드리지 않는다. 실행 끝에 원본에서 바뀐 파일 수를 출력한다
- 학생 조작 지점: `USE_SAVEPOINT`, `AGENT_ACTIONS`, `AGENT_REPORT`
- 교훈 지점: 건수만 비교하면 차이가 1건이지만 파일별로 대조하면 어긋난 파일이 3개다. 저장 지점이 없으면 되돌릴 수 없다
- 산출물: `results/report_vs_record.png`, `results/change_table.csv`

| 난수로 에이전트의 행동을 흉내 | 난수로 만든 결과를 AI의 행동으로 읽게 만들 위험이 있다 |
