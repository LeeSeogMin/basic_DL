# 12주차 계획서 — AI 코딩 에이전트와 책임 있는 자동화

## 1. 장의 역할

12주차는 AI 코딩 에이전트를 활용해 작은 Python 도구를 만들고, 그 과정에서 작업 분해, 프롬프트 명세, 코드 리뷰, 보안 점검을 경험하는 장이다. 학생은 AI가 코드를 대신 쓸 수 있다는 사실보다, AI가 쓴 코드를 읽고 검증하고 고치는 능력이 왜 필요한지를 이해한다.

이 장은 새로운 딥러닝 이론을 추가하지 않는다. 대신 2주차(AI 코딩 작업실)와 11주차(생성형 AI 원리와 폐해)에서 배운 개념을 실제 코딩 작업에 적용한다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. AI 코딩 에이전트가 코드를 생성하는 과정을 설명한다.
2. 하나의 작업을 AI에게 맡길 수 있는 작은 단위로 나눈다.
3. AI에게 명확한 프롬프트를 작성한다.
4. AI가 생성한 코드를 읽고, 의도와 다른 부분을 찾아 수정한다.
5. 코드에 파일 삭제, 외부 전송, 비밀키 노출 같은 보안 위험이 있는지 점검한다.

## 4. 실습 설계

### 실습 파일

- `practice/chapter12/code/12-1-ai-coded-tool.py`

### 실습 내용

1. 이미지 크기 변환 도구를 Python으로 만든다.
2. 코드에 보안 점검 기능을 포함한다. 파일 삭제 명령, 외부 전송 코드, 비밀키 하드코딩 여부를 검사한다.
3. 점검 결과를 화면에 출력하고 CSV로 저장한다.
4. 전체 과정에서 AI에게 요청한 프롬프트와 내가 수정한 부분을 기록한다.

### 예상 결과 파일

- `practice/chapter12/results/12-1-ai-coded-tool.evidence.json`
- `practice/chapter12/results/security_check_report.csv`

## 5. 책임 있는 AI 체크

| 점검 항목 | 질문 |
|---|---|
| 코드 이해 | AI가 만든 코드의 각 함수가 무엇을 하는지 설명할 수 있는가 |
| 보안 위험 | 파일 삭제, 외부 전송, 비밀키 노출 코드가 없는지 확인했는가 |
| 개인정보 | 코드가 개인정보를 수집하거나 전송하지 않는가 |
| AI 기록 | AI에게 요청한 프롬프트와 내가 수정한 부분을 기록했는가 |
| 실행 검증 | AI가 만든 코드를 직접 실행하고 결과를 확인했는가 |

5. 책임 있는 AI 체크리스트
