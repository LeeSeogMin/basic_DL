# 12주차 계획서 — AI 코딩 에이전트와 책임 있는 자동화

## 1. 장의 역할

12주차는 AI에게 코드를 맡기는 법이 아니라, **맡긴 결과를 사람이 확인하는 법**을 다루는 장이다. 11주차에서 생성형 AI의 답을 검증했다면, 이번 장에서는 검증 대상이 문장이 아니라 실행되는 코드로 바뀐다. 틀린 문장은 읽고 넘기면 끝나지만, 틀린 코드는 실행하는 순간 파일을 지우거나 데이터를 밖으로 내보낸다.

수업의 중심은 두 가지다. 하나는 **무엇을 만들지 문장으로 먼저 적는 일**(명세), 다른 하나는 **실행 전에 코드를 읽는 일**(점검)이다. 둘 다 AI가 대신해 줄 수 없는 자리다.

AI 도구(Copilot, ChatGPT, Claude 등)는 학생이 수업 중 직접 쓴다. 이 장의 실습 코드는 외부 API를 호출하지 않는다. 우리가 만드는 것은 **AI가 만든 코드를 사람이 점검하는 도구**다.

대상은 학부 2학년이다. 1차시 이론 강의, 2차시 실습으로 나눠 진행한다.

## 2. 학습 목표

1. 코딩 에이전트와 자동완성이 맡는 범위 차이를 설명한다.
2. 큰 요구를 확인 가능한 작업 단위로 쪼갠다.
3. 프롬프트를 입력·출력·금지·실패 네 칸의 명세로 쓴다.
4. AI가 만든 코드를 정해진 순서로 읽고 위험 신호를 찾는다.
5. AI 도구에 넣지 말아야 할 자료를 구분한다.
6. 자동화 결과의 책임이 어디에 있는지 말한다.

## 4. 2차시 실습 설계

실습은 두 개다. 각각 노트북에서 몇 초 안에 끝난다. 외부 API를 호출하지 않고, 인터넷 연결도 필요 없다.

### 실습 12.1 — 명세를 먼저 쓰고, 그대로 만든다

- 파일: `practice/chapter12/code/12-1-spec-to-tool.py`
- 데이터: `practice/chapter12/sample_folder/` (합성 예제 폴더, 파일 11개)
- 구성: 코드 맨 위에 도구의 명세(입력·출력·하면 안 되는 일·실패 시 동작)를 먼저 적고, 그 아래에 구현을 둔다
- 학생 조작 지점: `TARGET_FOLDER_NAME`, `CHART_TOP_N`, `SIZE_UNIT`
- 성취 지점: 실행하면 명세 6개 항목을 실제 동작과 하나씩 대조해 점검표로 출력한다. 읽기 전용 여부는 실행 전후 파일 해시를 비교해 확인한다
- 산출물: `results/folder_report.png`, `results/folder_extension_table.csv`

### 실습 12.2 — 실행하기 전에 코드를 점검한다

- 파일: `practice/chapter12/code/12-2-code-safety-check.py`
- 검사 대상: `_sample_safe.py`(합성 예제), `_sample_risky.py`(합성 예제), `12-1-spec-to-tool.py`(우리가 만든 도구)
- 찾는 신호 6종: 파일 삭제 / 외부 전송 / 셸 명령 실행 / 하드코딩된 비밀키 / 멈추지 않는 반복 / 파일 쓰기
- 안전 규칙: 검사 대상을 **실행하지 않고 import 하지도 않는다.** `read_text` 로 읽을 뿐이다. `_sample_risky.py` 는 밑줄로 시작해 실행 증거 게이트도 건드리지 않고, 파일 첫머리에서 `raise SystemExit` 로 한 번 더 막아 두었다. 위험 신호는 문자열 패턴 수준으로만 넣었고 실제로 파괴적인 동작을 하는 코드는 없다
- 학생 조작 지점: `SCAN_TARGETS`, `SECRET_WORDS`, `SNIPPET_CHARS`
- 교훈 지점: "높음 7건"이 악성 판정이 아니고 "0건"이 안전 증명도 아니다. 도구는 판단할 자리를 표시할 뿐이다
- 산출물: `results/safety_report.png`, `results/safety_findings.csv`

### 개념 그림 생성

- 파일: `practice/chapter12/code/12-0-concept-figures.py`
- 산출물: `results/fig12-1-autocomplete-vs-agent.png`, `results/fig12-2-task-breakdown.png`, `results/fig12-3-responsibility-line.png`
