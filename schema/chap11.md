# 11주차 계획서 — 생성형 AI의 원리와 폐해: 환각, 편향, 출처 검증

## 1. 장의 역할

11주차는 학생이 매일 쓰는 생성형 AI의 속을 열어 보는 장이다. "AI가 왜 그럴듯한 거짓말을 하는가"를 태도 문제나 윤리 훈화로 다루지 않고, **다음 단어를 확률로 고르는 계산 절차**에서 곧장 끌어낸다.

앞 장(10주차 텍스트 분류)까지는 이미 있는 문장을 나누는 일을 했다. 이번 장에서는 문장을 만드는 쪽으로 넘어간다. 만드는 절차를 학생이 직접 numpy로 구현하면, 환각이 고장이 아니라 절차의 당연한 결과라는 점이 드러난다.

외부 API를 한 줄도 쓰지 않는다. API 키가 필요한 코드를 두지 않는다. 언어모델의 원리는 코드 안에 넣은 합성 한국어 문장에서 센 n-gram 빈도표로 보여준다.

대상은 학부 2학년이다. 1차시 이론, 2차시 실습으로 나눈다.

## 2. 학습 목표

1. 언어모델이 한 번에 하는 일이 "다음 단어 하나 고르기"임을 설명한다.
2. 빈도표를 확률표로 바꾸고, 확률대로 단어를 이어 붙여 문장을 만든다.
3. 온도가 확률 분포 모양을 어떻게 바꾸는지 그림으로 읽는다.
4. 환각이 왜 기계적으로 생기는지 갈라지는 지점을 짚어 설명한다.
5. 편향이 학습 자료의 빈도 차이에서 나오는 것을 빈도표에서 확인한다.
6. AI 답변을 확인됨·불확실·틀림·판단 보류로 나누고 근거 주소를 적는다.

## 3. 1차시 이론 절 구성

| 절 | 제목 | 핵심 내용 | 시각 자료 |
|---|---|---|---|
| 1 | 언어모델은 무엇을 하는가 | 문장 전체를 계획하지 않는다. 다음 한 단어만 고른다 | 그림 11.1 |
| 2 | 다음 토큰 예측 — 확률표에서 단어 하나 뽑기 | 토큰, 빈도 → 확률, 뽑기, 온도 | 그림 11.2 |
| 3 | 프롬프트는 명령인가 데이터인가 | 프롬프트는 앞에 붙는 글이다. 조건이지 명령이 아니다 | 표 11.1 |
| 4 | 환각이 생기는 이유 | 확률이 갈리는 지점, "모른다"가 표에 없다 | 그림 11.3 |
| 5 | 편향은 어디서 오는가 | 학습 자료의 빈도 차이가 그대로 확률 차이가 된다 | 표 11.2 |
| 6 | AI 답변을 검증하는 절차 | 4단계 절차 + 검증표(수업 활동) | 표 11.3, 표 11.4 |
| 7 | 직접 움직여 보는 웹 자료 | 외부 시각 자료 4건 | 링크 표 |

6절의 검증 실습(같은 질문을 여러 방식으로 묻기, 수치·인물·논문 대조)은 코드가 아니라 **수업 활동**이다. 표와 절차로만 넣는다. 학생이 쓰는 AI 도구는 각자 준비한 것을 쓴다.

## 4. 2차시 실습 설계

실습 두 개 모두 numpy만 쓴다. 노트북에서 몇 초 안에 끝난다. 인터넷 연결이 필요 없다.

### 공용 모듈

- 파일: `practice/chapter11/code/_tinylm.py`
- 합성 한국어 문장 12종과 등장 횟수, 빈도표·확률표·온도·생성 함수를 담는다.
- 문장은 모두 "누가 / 언제 / 어디서 / 무엇을 / 어떻게 한다" 다섯 어절이다.
- 이 세계에서 참인 문장은 이 12종뿐이다. 목록에 없으면 어법이 맞아도 틀린 문장이다.
- 밑줄로 시작하는 이름이라 실행 증거 게이트가 직접 실행하지 않는다.

### 실습 11.1 — 다음 단어를 예측하는 작은 언어모델

- 파일: `practice/chapter11/code/11-1-next-word.py`
- 데이터: 합성 한국어 문장 12종, 횟수만큼 펼치면 27개, 어휘 21개
- 학생 조작 지점: 파일 상단의 `START_WORD`, `N_WORDS`
- 출력: 빈도표 → 확률표 → 단계별 선택 → 만들어진 문장 5개와 학습 문장 대조
- 성취 지점: 확률표를 보고 다음 단어를 스스로 예측한 뒤, 모델이 뽑은 단어와 맞춰 본다
- 교훈 지점: `P(파이썬을 | 실습실에서)`와 `P(파이썬을 | 도서관에서)`가 다른 이유가 뜻이 아니라 빈도다
- 산출물: `results/next_word_probs.png`, `results/next_word_table.csv`, `results/next_word_sentences.csv`

### 실습 11.2 — 환각은 어디서 생기는가

- 파일: `practice/chapter11/code/11-2-hallucination.py`
- 같은 모델에 온도만 바꾼다. 학생 조작 지점은 `TEMPERATURES`, `START_WORD`
- 온도마다 문장 200개를 만들고 학습 문장에 있던 조합인지 센다
- 갈라진 어절을 대괄호로 표시해 환각이 만들어지는 순간을 짚는다
- 교훈 지점: 온도를 낮춰도 환각이 사라지지 않는다. 1등 쪽으로 굳을 뿐이다
- 산출물: `results/hallucination_by_temperature.png`, `results/hallucination_examples.csv`, `results/hallucination_summary.csv`

### 개념 그림 생성

- 파일: `practice/chapter11/code/11-0-concept-figures.py`
- 산출물: `results/fig11-1-next-token-loop.png`, `results/fig11-2-sharp-vs-flat.png`, `results/fig11-3-where-hallucination.png`
- fig11-2의 막대 높이는 `_tinylm.py`에서 실제로 센 확률이다. 나머지 두 장은 개념 도식이다.
- 한글 폰트 도우미: `practice/chapter11/code/_krfont.py` (4장 파일과 같다. 폰트가 없으면 영어 라벨로 자동 전환)
