# 11주차 계획서 — 생성형 AI의 원리와 폐해: 환각, 편향, 출처 검증

## 1. 장의 역할

11주차는 학생이 이미 사용하고 있는 생성형 AI가 어떤 원리로 문장을 만드는지 이해하고, 그 원리에서 환각과 편향이 왜 발생하는지 파악하는 장이다. 학생은 "다음 토큰 예측"이라는 언어모델의 핵심 동작을 간단한 n-gram 모델로 직접 실행해 본 뒤, AI 답변을 검증하는 절차를 훈련한다.

이 장은 AI를 잘 쓰는 법보다 AI 답변을 의심하는 법에 초점을 둔다. 프롬프트를 바꾸면 답이 달라지는 현상, 그럴듯하지만 사실이 아닌 답변(환각), 특정 관점으로 치우친 답변(편향)을 학생이 직접 발견하고 기록한다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. 언어모델이 "다음 토큰 예측"으로 문장을 생성하는 원리를 설명한다.
2. 프롬프트가 모델의 출력을 어떻게 바꾸는지 예를 들어 설명한다.
3. 환각이 발생하는 구조적 이유를 말한다.
4. 편향이 학습 데이터에서 오는 과정을 설명한다.
5. AI 답변을 "확인됨", "불확실", "틀림", "판단 보류" 네 등급으로 분류한다.
6. AI가 제시한 수치나 사례의 출처를 확인하는 절차를 수행한다.
7. 간단한 n-gram 모델을 실행하고 다음 단어 예측 결과를 해석한다.

## 4. 실습 설계

### 실습 파일

- `practice/chapter11/code/11-1-ai-answer-audit.py`

### 실습 내용

1. 간단한 텍스트 말뭉치에서 n-gram(bigram/trigram) 빈도를 세어 언어모델을 만든다.
2. 시작 단어를 주면 다음 단어를 확률 기반으로 예측하여 문장을 생성한다.
3. 같은 시작 단어로 여러 번 생성하여 결과가 달라지는 것을 보여준다(시드 변경).
4. 미리 준비한 AI 답변 예시(환각 포함)를 읽고 검증 항목별로 점검표를 출력한다.
5. 검증 결과를 CSV로 저장한다.

### 예상 결과 파일

- `practice/chapter11/results/11-1-ai-answer-audit.log`
- `practice/chapter11/results/11-1-ai-answer-audit.evidence.json`
- `practice/chapter11/results/ai_answer_audit.csv`

## 5. 책임 있는 AI 체크

학생은 AI 답변을 검증할 때 다음을 확인한다.

| 점검 항목 | 질문 |
|---|---|
| 사실 검증 | AI가 제시한 수치, 인물, 연도가 실제와 맞는가 |
| 출처 확인 | AI가 근거로 든 논문, URL, 사례가 실재하는가 |
| 과장 표현 | "항상", "완벽히", "명백히" 같은 과장 표현을 쓰지 않았는가 |
| 편향 점검 | 특정 관점만 제시하고 반대 논거를 빠뜨리지 않았는가 |
| 환각 식별 | 그럴듯하지만 확인할 수 없는 내용이 있는가 |

## 6. 제출물

1. 실행 로그 또는 화면
2. n-gram 모델 생성 결과 (다음 단어 예측 출력)
3. AI 답변 검증표 (CSV 또는 수기)
4. 환각 사례 1개와 수정 프롬프트
5. 출처 확인 실패 사례 1개
6. 책임 있는 AI 사용 체크리스트
