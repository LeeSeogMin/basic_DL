# 6주차 계획서 — 학습이란 무엇인가: 손실함수와 경사하강법

## 1. 장의 역할

6주차는 "학습"이라는 말의 속을 여는 장이다. 4장 실습에서 로지스틱 회귀는 `수면시간 = -1.59 x 공부시간 + 13.96` 이라는 선을 내놓았다. 6장은 모델이 그 두 숫자를 고르는 과정을 다룬다. 기계가 쓰는 규칙은 한 줄이다. 틀린 정도를 숫자 하나로 재고(손실함수), 그 숫자가 줄어드는 쪽으로 조금씩 움직인다(경사하강법).

손실함수의 주 설명은 **교차 엔트로피**로 한다(2026-10-13 변경). 4장의 로지스틱 회귀, 9장의 숫자 분류, 텍스트 언어모델의 다음 토큰 예측이 모두 분류이고 모두 교차 엔트로피를 쓴다. 평균제곱오차(MSE)는 "회귀에서는 이것을 쓴다"는 보조 절 하나로 줄인다.

미분을 배우지 않은 학생을 기준으로 쓴다. 기울기는 "어느 쪽으로 가야 손실이 줄어드는지 알려주는 화살표"로 설명하고, 식은 갱신 규칙 한 줄, 교차 엔트로피 한 줄(−log p), 평균제곱오차 한 줄만 쓴다. 역전파는 미분 기호 없이 곱셈 사슬 숫자 예제 하나로 보여준다. 나머지는 전부 그림과 실행 로그로 보여준다.

대상은 학부 2학년이다.

## 2. 학습 목표

1. 모델이 "틀렸다"는 것을 어떻게 아는지 손실함수로 설명한다.
2. 분류 문제에서 교차 엔트로피가 정답 쪽 확률이 낮을수록 손실을 키운다는 것을 설명하고, p 값 하나로 손실을 계산한다.
2-1. 회귀 문제에서는 평균제곱오차를 쓴다는 것을 안다.
3. 기울기가 알려주는 것이 방향이라는 점을 설명한다.
4. 경사하강법의 갱신 규칙 한 줄을 읽고, 걸음마다 w가 어떻게 바뀌는지 표에서 확인한다.
4-1. 역전파가 출력 쪽에서 입력 쪽으로 곱셈을 이어 가며 가중치마다 기울기를 구하는 과정을 숫자로 따라간다.
5. 학습률이 너무 작을 때와 너무 클 때 손실 곡선이 어떻게 달라지는지 구분한다.
6. epoch와 batch를 가중치 갱신 횟수로 환산한다.
7. 학습 곡선을 보고 학습이 잘 되고 있는지 판단한다.

## 4. 실습 설계

실습은 두 개다. 각각 노트북에서 몇 초 안에 끝난다. GPU가 필요 없다.

### 실습 6.1 — 손실 곡선 위를 한 걸음씩 내려간다

- 파일: `practice/chapter6/code/6-1-gradient-descent.py`
- 문제: 손실(w) = (w − 3)² + 2. 최저점을 미리 알고 시작한다. 기계가 그 답을 어떻게 찾아가는지 걸음마다 본다
- 손실 곡선을 그릇 모양 식으로 직접 준다. 교차 엔트로피로 만든 곡선도 바닥 근처에서는 그릇 모양이라 갱신 규칙의 움직임은 같다. 이 실습은 갱신 규칙만 떼어 보는 실습이므로 손실 종류를 바꾸지 않는다
- 학생 조작 지점: `LEARNING_RATE`, `START_W`, `N_STEPS`
- 구현: scikit-learn을 쓰지 않고 numpy로 직접 계산한다. 갱신 규칙 한 줄이 코드에 그대로 보이게 한다
- 출력: 걸음마다 w, 손실, 기울기, 이동거리, 다음 w를 표로 찍는다
- 성취 지점: 학습률을 바꾸면 궤적의 점 간격이 눈에 띄게 달라진다
- 산출물: `results/gradient_descent_path.png`, `results/gradient_descent_steps.csv`

### 실습 6.2 — 학습률 셋으로 학습을 일부러 망가뜨린다 (2026-10-13 분류로 변경)

- 파일: `practice/chapter6/code/6-2-learning-rate.py`
- 데이터: 합성 학생 200명. 공부시간을 0~10시간에서 고르고, 통과 확률 = 시그모이드(1.2 × 공부시간 − 6.0)로 통과·탈락을 뽑는다
- 모델: 통과 확률 = 시그모이드(w × 입력 + b). 손실은 교차 엔트로피. 입력은 공부시간에서 5를 뺀 값이다(`SHIFT_INPUT`)
- 입력을 옮기는 이유: 시험 계산에서 공부시간을 그대로 넣으면 어떤 학습률도 200에포크 안에 바닥에 깔끔하게 닿지 않았다. 옮기지 않은 경우는 "해 보기"로 돌린다
- 학습률 셋: 0.003(너무 작다) / 0.3(알맞다) / 30(너무 크다). 교차 엔트로피 분류에서는 학습률이 커도 손실이 `inf`로 넘치지 않고 튄다. 이 차이를 본문에 적는다
- 그림 두 칸: ① 에포크별 손실과 도달할 수 있는 가장 낮은 손실(점선) ② 학습률별로 찾은 통과 확률 곡선과 학생 점
- 학생 조작 지점: `LEARNING_RATES`, `N_EPOCHS`, `SHIFT_INPUT`
- 산출물: `results/learning_rate_curves.png`, `results/learning_rate_table.csv`
