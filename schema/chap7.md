# 7주차 계획서 — 과적합과 일반화: 외운 모델과 이해한 모델

## 1. 장의 역할

7주차는 "훈련 데이터에서 잘 맞는 모델이 왜 실제로는 실패하는가"를 학생이 눈으로 확인하는 장이다. 4장에서 훈련 성적과 테스트 성적이 뒤집힌 사례를 남겨 두고 "7장에서 다룬다"고 예고했다. 이 장이 그 예고를 회수한다.

4장은 데이터를 훈련과 테스트 둘로만 나눴다. 7장은 검증 데이터를 넣어 셋으로 넓힌다. 모델을 고르는 일과 성적을 재는 일을 서로 다른 데이터에 맡기는 이유를 설명한다.

수식을 앞세우지 않는다. 다항식 차수를 모델 복잡도의 손잡이로 쓰고, 차수를 돌릴 때 곡선 모양과 오차 표가 함께 움직이는 것을 보여준다. 정규화와 dropout은 원리를 구현하지 않고 직관만 다룬다.

대상은 학부 2학년이다. 1차시 이론 강의, 2차시 실습으로 나눠 진행한다.

## 2. 학습 목표

1. 과적합이 무엇인지, 외운 모델과 이해한 모델의 차이로 설명한다.
2. 훈련 성능과 검증 성능의 간격을 보고 과적합을 알아챈다.
3. 검증 데이터가 왜 따로 필요한지, 테스트 데이터와 무엇이 다른지 설명한다.
4. 모델 복잡도를 올릴 때 훈련 오차와 검증 오차가 각각 어떻게 움직이는지 말한다.
5. 과적합을 고치는 네 가지 방법(데이터 늘리기, 모델 줄이기, 정규화, dropout)을 구분한다.
6. 4장 실습 4.1에서 훈련·테스트 성적이 뒤집힌 이유를 과적합 개념으로 해석한다.

## 4. 2차시 실습 설계

실습은 두 개다. 각각 노트북에서 몇 초 안에 끝난다. GPU가 필요 없다. 두 실습 모두 합성 데이터를 쓴다.

### 실습 7.1 — 일부러 과적합 만들기

- 파일: `practice/chapter7/code/7-1-overfit.py`
- 데이터: `cos(1.5πx)` 곡선에 잡음을 섞은 합성 데이터. 훈련 30개, 테스트 200개
- 학생 조작 지점: 파일 상단의 `DEGREES`, `NOISE_LEVEL`, `N_SAMPLES`
- 비교 대상 셋: 다항식 차수 1(과소적합) / 4(알맞음) / 15(과적합)
- 성취 지점: 차수를 올리면 훈련 오차는 내려가고 테스트 오차는 올라가는 것을 한 그림·한 표로 동시에 본다
- 차수 1·4·15 조합은 scikit-learn 공식 예제 Underfitting vs. Overfitting과 같다
- 산출물: `results/overfit_curves.png`, `results/overfit_table.csv`

### 실습 7.2 — 과적합 진단하고 고치기

- 파일: `practice/chapter7/code/7-2-diagnose.py`
- 데이터: 같은 합성 곡선 데이터 1000개를 훈련 후보 700 / 검증 200 / 테스트 100으로 나눔
- 학생 조작 지점: `MAX_DEGREE`, `FIT_SIZE`, `LEARNING_DEGREE`, `NOISE_LEVEL`, `N_REPEATS`
- 진단 1(복잡도 곡선): 차수를 1부터 10까지 올리며 훈련·검증 오차를 나란히 그린다
- 진단 2(학습 곡선): 차수를 10으로 고정하고 훈련 데이터를 20개부터 300개까지 늘린다
- 측정 방법: 같은 크기의 훈련 데이터를 최대 9번 다르게 뽑아 오차의 **중앙값**을 쓴다. 한 번만 뽑으면 어느 점이 뽑혔는지에 따라 값이 들쭉날쭉해 두 곡선의 관계가 안 보인다
- 교훈 지점: 두 처방(모델 줄이기·데이터 늘리기)이 각각 어느 그림에 대응하는지 확인하고, 마지막에 테스트 데이터를 딱 한 번 쓴다
- 산출물: `results/diagnose_curves.png`, `results/complexity_curve.csv`, `results/learning_curve.csv`
