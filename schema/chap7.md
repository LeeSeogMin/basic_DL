# 7주차 계획서 — 과적합과 일반화: 외운 모델과 이해한 모델

## 1. 장의 역할

7주차는 모델이 훈련 데이터를 외우는 것과 새로운 데이터에서도 잘 작동하는 것이 다르다는 사실을 학생이 직접 확인하는 장이다. 학생은 일부러 과적합 모델을 만들고, 훈련 정확도는 높지만 테스트 정확도는 낮은 상황을 그래프로 관찰한다.

이 장은 4주차(머신러닝 첫걸음)와 6주차(손실함수와 경사하강법)를 이어받아, 모델을 평가할 때 훈련 성능만 보면 위험하다는 핵심 교훈을 전달한다. 8주차 중간 프로젝트 전 마지막 기초 장이므로, 학생이 모델 평가와 진단을 스스로 할 수 있는 수준까지 도달해야 한다.

이 장은 다음 원칙을 따른다.

- 과적합을 추상적으로 설명하지 않고, 실습에서 눈으로 확인한다.
- 시험 비유(연습문제 외우기 vs 원리 이해)로 직관을 먼저 만든다.
- 모델 복잡도를 바꾸며 훈련/테스트 성능 변화를 그래프로 관찰한다.
- 정규화와 dropout은 직관 수준에서 소개하고, 구현 실습은 이후 장에서 다룬다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. 과적합이 무엇인지 자기 말로 설명한다.
2. 훈련 정확도가 높은데 테스트 정확도가 낮으면 과적합을 의심한다.
3. 검증 데이터의 역할을 설명한다.
4. 모델 복잡도를 높이면 훈련 성능은 올라가지만 테스트 성능은 꺾일 수 있다는 점을 안다.
5. 과적합을 줄이는 방법 3가지 이상을 말한다.
6. 훈련 성능만 보고 모델이 좋다고 주장하지 않는다.

## 4. 실습 설계

### 실습 파일

- `practice/chapter7/code/7-1-overfitting-demo.py`

### 실습 내용

1. scikit-learn의 `make_classification`으로 합성 데이터 100개를 만든다.
2. 데이터를 훈련 데이터와 테스트 데이터로 나눈다.
3. 과적합 모델(결정 트리, `max_depth=None`)을 학습시킨다.
4. 적절한 모델(결정 트리, `max_depth=3`)을 학습시킨다.
5. 두 모델의 훈련 정확도와 테스트 정확도를 비교 출력한다.
6. `max_depth`를 1부터 20까지 바꾸며 훈련/테스트 정확도 변화를 그래프로 그린다.
7. 그래프를 PNG로 저장한다.

## 5. 책임 있는 AI 체크

학생은 AI에게 과적합 해결책을 요청할 수 있다. 단, 다음을 확인해야 한다.

| 점검 항목 | 질문 |
|---|---|
| 훈련 성능 과장 | 훈련 정확도만 보고 모델이 좋다고 단정했는가 |
| 테스트 성능 확인 | 테스트 데이터에서의 성능을 함께 확인했는가 |
| 과적합 인식 | 훈련 정확도와 테스트 정확도의 차이가 크면 과적합이라고 판단했는가 |
| 복잡도 의식 | 모델을 무조건 복잡하게 만드는 것이 좋다고 말하지 않았는가 |
| AI 답변 검증 | AI가 제안한 해결책이 실습 상황에서 실제로 적용 가능한지 따져보았는가 |
