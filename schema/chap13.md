# 13주차 계획서 — 나만의 AI 앱 만들기

## 1. 장의 역할

13주차는 지금까지 배운 모델을 사용자가 직접 입력하고 결과를 받아볼 수 있는 데모 앱으로 만드는 장이다. 학생은 모델을 학습시키는 것에서 한 걸음 나아가, 모델의 출력을 사용자에게 보여주고 그 한계를 함께 안내하는 경험을 한다.

이 장의 핵심은 화려한 앱을 만드는 것이 아니다. 모델이 틀릴 수 있다는 사실을 사용자에게 어떻게 알려야 하는지, 입력과 출력의 형태를 어떻게 정하는지를 경험하는 것이다.

## 2. 학습 목표

학생은 수업 후 다음을 할 수 있어야 한다.

1. 학습된 모델을 사용자 입력과 연결해 결과를 출력하는 앱을 만든다.
2. 데모 앱의 입력과 출력을 명확히 정의한다.
3. 모델의 한계를 사용자에게 안내하는 문구를 작성한다.
4. AI 도구를 사용해 앱을 만들고, 사용 과정을 기록한다.

## 4. 실습 설계

### 실습 파일

- `practice/chapter13/code/13-1-ai-demo-app.py`

### 실습 내용

1. scikit-learn으로 간단한 분류 모델을 학습시킨다 (숫자 분류 또는 감성 분석).
2. 사용자가 콘솔에서 입력을 넣으면 모델이 예측 결과를 출력한다.
3. 예측 결과와 함께 모델의 신뢰도와 한계 안내 문구를 출력한다.
4. 데모 모드에서는 미리 정해둔 입력으로 자동 실행해 결과를 보여준다.

## 5. 책임 있는 AI 체크

| 점검 항목 | 질문 |
|---|---|
| 한계 안내 | 앱이 모델의 한계를 사용자에게 안내하는가 |
| 과장 금지 | "100% 정확" 같은 과장 표현이 출력에 없는가 |
| 입력 검증 | 예상치 못한 입력에 앱이 오류 없이 대응하는가 |
| 개인정보 | 앱이 사용자 입력을 외부로 전송하지 않는가 |
| AI 기록 | AI 도구 사용 과정을 기록했는가 |

4. AI 사용 로그
