# 13주차 계획서 — 나만의 AI 앱 만들기: 데모와 사용자 경험

## 1. 장의 역할

13주차는 학습한 모델을 남이 쓸 수 있는 앱으로 만드는 장이다. 새 알고리즘을 배우지 않는다. 6장의 로지스틱 회귀를 그대로 쓰고, 그 앞뒤에 입력 검사·확률·판단 근거·한계 안내를 붙인다. 이어서 앱이 화면에 표시한 확률을 실제로 맞은 비율과 대조하고, 모델이 배운 범위 밖의 입력에서 그 확률이 어떻게 어긋나는지 센다.

실습 코드는 AI 서비스를 호출하지 않고 인터넷도 쓰지 않는다. 데이터는 컴퓨터로 만든 합성 날씨 데이터이며 실제 공공자전거 대여 기록이 아니다.

대상은 학부 2학년이다. 2026년 11월 개정에서 앱 도구·공개 서비스 문서와 국내 법령·지침을 다시 확인했고, 실습 두 개를 교체했다. 분량은 PDF 20쪽 이하로 둔다.

## 2. 학습 목표

1. 모델과 앱의 차이를 설명하고, 앱이 하는 일 다섯 가지를 말한다.
2. 입력 검사, 확률, 판단 근거, 한계 안내를 화면에 넣은 앱 파일을 만든다.
3. 앱이 화면에 표시한 확률을 실제로 맞은 비율과 대조한다.
4. 모델이 배운 범위 밖의 입력에 경고를 붙여야 하는 이유를 실행 결과로 설명한다.
5. 앱을 남에게 건네는 방법 세 가지를 비교하고, 받지 않아야 할 입력을 구분한다.

## 4. 실습 설계

실습은 두 개다. 각각 노트북에서 몇 초 안에 끝난다. numpy·pandas·matplotlib·scikit-learn만 쓴다.

공통 데이터·모델은 `practice/chapter13/code/_bikedata.py`에 둔다. 합성 날씨 1,500일(기온 3~26도), seed 42, 훈련 1,050일·테스트 450일, 표준화 + 로지스틱 회귀. 정답 규칙은 "기온이 24도에 가까울수록, 비와 바람이 적을수록 대여가 많다"이다. 모델은 26도 이하만 보므로 24도를 넘으면 대여가 줄어든다는 것을 배우지 못한다.

### 실습 13.1 — 모델을 파일 한 개짜리 앱으로 내보낸다

- 파일: `practice/chapter13/code/13-1-build-app.py`
- 동작: 모델에서 숫자 10개(입력 3개의 평균·표준편차·무게, 절편)를 꺼내 `my_app.html`에 담는다. 꺼낸 숫자로 계산한 확률을 테스트 450일에서 원래 모델과 비교하고, 차이가 0.001을 넘으면 멈춘다. 시험 입력 6건을 답함·범위 밖 경고·입력 거절로 처리한다
- 앱 파일: 외부 자원을 불러오지 않는다. 브라우저 안에서만 계산하고 입력을 저장하거나 보내지 않는다. 화면 맨 위에 "AI 모델이 계산한 예측"이라는 문구가 항상 나온다
- 학생 조작 지점: `APP_TITLE`, `MODEL_LIMITS`, `MY_INPUTS`
- 교훈 지점: 앱이 받는 범위와 모델이 배운 범위는 다르다. 기온 36도에 확률 1.000이 나오지만 범위 밖 경고가 붙는다
- 산출물: `results/my_app.html`, `results/app_check.png`, `results/app_check.csv`
- 그림 13.4(`results/app_screen.png`)는 실습 코드가 만들지 않는다. `my_app.html`의 사본에 5번 입력을 넣고 Chrome 헤드리스 모드로 저장한 화면이다. 앱 화면 구성을 바꾸면 다시 찍는다

### 실습 13.2 — 화면의 확률을 실제로 맞은 비율과 대조한다

- 파일: `practice/chapter13/code/13-2-prob-check.py`
- 데이터: 실습 13.1의 테스트 450일과, 같은 규칙으로 새로 만든 여름 날씨 600일(기온 22~38도, seed 7). 모델은 다시 학습시키지 않는다
- 동작: 확신(고른 답 쪽의 확률)을 다섯 구간으로 묶어 구간별 맞은 비율을 센다. 범위 밖 경고가 붙은 답과 안 붙은 답을 나눠 평균 확신과 맞은 비율을 비교한다
- 학생 조작 지점: `NEW_TEMP`, `NEW_DAYS`, `NEW_SEED`, `HIGH_CONFIDENCE`
- 교훈 지점: 배운 범위 안에서는 표시한 확신과 맞은 비율이 비슷하다. 새 데이터에서는 평균 확신 0.978에 맞은 비율 0.622다. 경고가 붙은 451일의 맞은 비율은 0.523이고, 틀린 답 227건 중 215건에 경고가 붙었다. 경고는 "틀렸다"가 아니라 "확인한 적이 없다"는 뜻이다
- 산출물: `results/confidence_check.png`, `results/confidence_table.csv`
