# 5주차 계획서 — 신경망의 직관: 작은 뉴런들이 만드는 판단

## 1. 장의 역할

5주차는 4장에서 로지스틱 회귀가 찾은 경계선을 뉴런 하나의 계산으로 다시 읽는 장이다. 4장 실습 4.1은 모델이 찾은 선을 `수면시간 = -1.59 x 공부시간 + 13.96` 식으로 꺼내 보였다. 5장은 그 선을 긋는 장치가 뉴런 하나라는 데서 출발해, 뉴런 하나로는 못 푸는 문제(XOR)와 은닉층이 그 문제를 푸는 방식까지 간다.

수식 전개보다 그림과 실행 결과를 앞세운다. 학생이 상수 하나를 바꾸면 경계선이 움직이고 정확도가 달라지는 것을 직접 확인하게 한다.

대상은 학부 2학년이다. 1차시 이론 강의, 2차시 실습으로 나눠 진행한다.

## 2. 학습 목표

1. 뉴런 하나가 하는 계산을 `z = W1·x1 + W2·x2 + B` 로 쓴다.
2. 가중치를 바꾸면 경계선의 기울기가, 편향을 바꾸면 위치가 움직인다는 것을 확인한다.
3. 활성화 함수가 없으면 층을 쌓아도 직선 하나와 같다는 것을 설명한다.
4. XOR가 직선 하나로 안 풀리는 이유를 네 점의 배치로 설명한다.
5. 같은 데이터에서 은닉층 없는 모델과 있는 모델의 정확도를 비교한다.

## 3. 1차시 이론 절 구성

| 절 | 제목 | 핵심 내용 | 시각 자료 |
|---|---|---|---|
| 1 | 뉴런 하나는 무엇을 계산하는가 | 가중합 z, 4장 경계선과 같은 식 | 그림 5.1 뉴런 구조 |
| 2 | 가중치와 편향이 하는 일 | W는 기울기, B는 위치 | 그림 5.4 (실습 5.1 산출) |
| 3 | 활성화 함수는 왜 필요한가 | 계단·시그모이드·ReLU, 층 붕괴 | 그림 5.2, 그림 5.5 |
| 4 | 직선 하나로 못 나누는 문제 | XOR 네 점의 배치 | 표 5.2 |
| 5 | 은닉층을 넣으면 무엇이 달라지는가 | 은닉 뉴런 두 개의 반평면을 출력 뉴런이 합친다 | 그림 5.3 |
| 6 | 다층 퍼셉트론 | 입력층·은닉층·출력층, 깊이와 폭 | — |
| 7 | 직접 움직여 보는 웹 자료 | 외부 시각 자료 4건 | 링크 표 |

## 4. 2차시 실습 설계

실습은 두 개다. 각각 노트북에서 몇 초 안에 끝난다. GPU가 필요 없다.

### 실습 5.1 — 뉴런 하나가 긋는 선

- 파일: `practice/chapter5/code/5-1-one-neuron.py`
- 데이터: 합성 학생 데이터 160명. 4장 실습 4.1과 같은 생성식·같은 seed를 쓴다
- 학생 조작 지점: 파일 상단의 `W1`, `W2`, `B`
- 성취 지점: 값 하나를 바꾸면 경계선이 움직이고 정확도가 0.800에서 0.644까지 내려간다
- 산출물: `results/one_neuron.png`, `results/activation_functions.png`

### 실습 5.2 — XOR: 직선 하나로 못 나누는 문제

- 파일: `practice/chapter5/code/5-2-xor.py`
- 데이터: 합성 XOR 데이터 240개. 네 모서리 주변에 표준편차 0.16의 잡음을 뿌렸다
- 학생 조작 지점: 파일 상단의 `HIDDEN_UNITS`, `NOISE`, `N_PER_CORNER`
- 비교 대상 둘: 은닉층 없는 모델(로지스틱 회귀) / 은닉 뉴런 4개짜리 MLP
- 교훈 지점: 같은 데이터에서 테스트 정확도가 0.431과 1.000으로 갈린다
- 산출물: `results/xor_comparison.png`

### 개념 그림 생성

- 파일: `practice/chapter5/code/5-0-concept-figures.py`
- 산출물: `results/fig5-1-neuron-anatomy.png`, `results/fig5-2-why-activation.png`, `results/fig5-3-folding-layers.png`
- fig5-2와 fig5-3은 손으로 정한 가중치를 실제로 계산해 그린다. 도식이 아니다
- 한글 폰트 도우미: `practice/chapter5/code/_krfont.py` (폰트가 없으면 영어 라벨로 자동 전환)
