# 기출 오답 노트 (합성 예제)

1. "학년별 인원 비율에 맞춰 뽑는 방법"을 단순무작위 추출로 골랐다
   → 정답은 층화 추출. 집단을 나눈 뒤 집단마다 뽑는다
2. 만족도 1~5점을 비율 척도로 골랐다
   → 정답은 서열 척도(수업에서는 등간 척도로 다루기도 한다). 0이 "없음"을 뜻하지 않는다
3. "수업이 재미있고 유익했습니까?"의 문제를 유도 질문이라고 썼다
   → 정답은 이중 질문. 한 문항에 두 가지를 묻는다
4. 신뢰도가 높으면 타당도도 높다고 골랐다
   → 틀림. 신뢰도가 높아도 엉뚱한 것을 측정할 수 있다
