# 사회조사방법론 (2학년 2학기) — 내 과목 폴더

이 폴더는 실습 12.2에서 쓰는 합성 예제다. 한 학생이 과목 하나의 시험 준비와
프로젝트 과제를 한 폴더에서 관리한다고 가정하고 만들었다.
파일 안의 날짜, 숫자, 응답은 모두 지어낸 값이다.

폴더 구성
  lectures/  주차별 강의 노트
  exam/      중간고사 준비 (범위 요약, 오답 노트)
  project/   조별 프로젝트: 소규모 설문조사 보고서
             data/responses_raw.csv 는 설문 원본 응답이다. 고치지 않는다
  todo.md    마감과 할 일

설문은 이름과 학번을 받지 않았다. 응답자는 R001 같은 번호로만 구분한다.
