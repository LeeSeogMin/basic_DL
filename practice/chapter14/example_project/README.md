# 리뷰 감성 분류기 (예시 프로젝트)

기말 프로젝트 폴더를 어떤 모양으로 만들면 되는지 보여주는 예시다.
실습 14.2의 점검 도구가 이 폴더를 읽어 통과 여부를 표로 낸다.

## 실행 방법

```bash
python run.py
```

## 폴더 구성

- `run.py` — 실행되는 코드
- `data/input_example.csv` — 입력 예시 (직접 지어낸 문장, 실제 리뷰가 아니다)
- `results/run.log` — 실행 결과 로그
- `results/scores.csv` — 정확도 표

## AI 도구 사용 기록

- 사용한 도구: AI 코딩 도우미
- 시킨 일: 단어 세기 부분의 반복문 초안 작성
- 직접 확인한 부분: 단어 목록을 내가 고쳐 넣고 12개 문장에서 결과를 하나씩 대조

## 이 프로젝트의 한계

- 문장이 12개뿐이라 결과를 일반화할 수 없다.
- 단어 목록에 없는 표현을 만나면 무조건 중립으로 판정한다.
- "불친절"에 "친절"이 들어 있어 두 단어가 같이 세어진다. 12개 중 1개를 이 이유로 틀렸다.
- 반어법("정말 좋겠다")을 구분하지 못한다.
